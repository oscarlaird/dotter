\chapter{The Bayesian Trie}
\label{chap:trie}

Dotter must determine the most likely string that the user is typing, based 
on observation of the user's signals.
To accomplish this, Dotter maintains a trie indicating the posterior probability
that any given prefix is a prefix of the user's target string.
To compare strings, we use the inequality notation $x \leq y$ to mean that the string $x$ is a prefix of the string $y$.
Letting $X$ (an unknown random variable) be the user's target string and $D$ be the user's signals, then the posterior probability 
that a given string, $a$, is a prefix of $X$ is given by:
$$
P(a \leq X | D) = \frac{P(D | a \leq X) P(a \leq X)}{P(D)}.
$$

In practice, we only keep track of the unnormalized posterior probabilities, $P(D | a \leq X) P(a \leq X)$.
However, since the root node, $\epsilon$, is the empty string, we have $P(\epsilon \leq X) = 1$ 
and thus the unnormalized posterior probability of the root node is $P(D)$, i.e., the normalizing constant.
Thus if we know the unnormalized posterior probabilities in our trie, we can convert these to normalized
posterior probabilities by dividing by the root node's unnormalized posterior probability.

The posterior probabilities are derived from the prior probabilities and the likelihoods.
In Dotter, both are subject to updates. The likelihood is updated as we receive signals from the user
and the prior is updated as our language model refines its predictions.

Our analysis has six parts:
\begin{enumerate}
    \item \textbf{Core Algorithms} (section~\ref{sec:core-algorithms}): we present the core algorithms for lazy
    calculation of the unnormalized posteriors.
    \item \textbf{Likelihood Tracking} (section~\ref{sec:likelihood-tracking}): we present the algorithm for lazy likelihood tracking.
    \item \textbf{Character Priors from Token Models} (section~\ref{sec:character-priors-from-token-models}): we present the algorithm for converting a token-based prior model to a character-based prior model.
    \item \textbf{Prior Tracking} (section~\ref{sec:prior-tracking}): we present the algorithm for calculating priors.
    \item \textbf{Maximum Truncation Compatible Descendant Likelihood} (section~\ref{sec:maximum-descendant-likelihood}): we present the algorithm for tracking ``maximum truncation compatible descendant likelihoods''.
    \item \textbf{The Complete Algorithms} (section~\ref{sec:complete-algorithm}): we present the complete algorithms.
\end{enumerate}

\section{Lazy Posterior Calculation: The Core Algorithms}
\label{sec:core-algorithms}

\begin{definition}[Alphabet]
An alphabet is a finite set.
\end{definition}

\begin{definition}[Character]
A character is an element of an alphabet.
\end{definition}

\begin{definition}[String]
A string is a sequence of characters.
\end{definition}

Throughout this chapter, we will let $\Lambda$ denote our alphabet which must include at least
the two special characters: space, $\sigma$, and stop, $\omega$.
The set of all strings over
this alphabet will be denoted $S$.

\begin{definition}[Substring]
We use the notation $s[i:j]$ to represent the subsequence of characters of $s$ from index $i$ to index $j-1$.
We also allow the notation $s[:-k]$ to represent the subsequence of characters of $s$ from index 0 to index $|s|-k-1$.
\end{definition}

\begin{definition}[Empty String]
    The empty string is the string of length 0, denoted $\epsilon$.
\end{definition}

\begin{definition}[String Inequality]
We say that a string $s$ is a prefix of a string $t$, and write this as $s \leq t$, if and only if there exists an integer $k$ such that $s = t[0:k]$.
\end{definition}

\begin{definition}[String Subtraction]
\label{def:string-subtraction}
    String subtraction refers to prefix removal.
    $x - y$ is defined as $x[|y|:]$.
    It is only defined if $y \leq x$.
\end{definition}

\begin{definition}[Properly Terminated String]
A string $h$ is properly terminated if and only if $h[i]=\omega \iff i=|h|-1$.
An unterminated string is one that does not contain the stop character.
An ``at most properly terminated string'' is one that is either properly terminated or unterminated.
\end{definition}

In this chapter, the set of all properly terminated strings will be denoted $H$.

\begin{definition}[Prefix Code]
    A prefix code is a set of strings such that no string is a prefix of another string in the set, i.e.,
    A set $C$ is a prefix code if and only if,
    $$
    \not\exists c_1, c_2 \in C, c_1 < c_2
    $$
\end{definition}

\begin{definition}[Complete Prefix Code]
    A complete prefix code, $C$, is a prefix code that covers the entire tree, i.e.,
    $$
    \forall x \in S, \exists c \in C, x \leq c \lor c \leq x
    $$
\end{definition}

\begin{definition}[Refinement]
    A prefix code, $A$, is a refinement of a prefix code, $B$,
    if every element of $A$ is an extension of some element of $B$, i.e.,
    $$
    \forall a \in A, \exists b \in B, a \geq b
    $$
    If this is the case, we write $A \geq B$.
\end{definition}

Refinement is a partial order over complete prefix codes.
These prefix codes form a lattice, so we may define the meet
and join of two prefix codes.

\begin{definition}[Meet]
    The meet of two prefix codes, $A$ and $B$, is the greatest lower bound of $A$ and $B$, i.e.,
    i.e.,
    it is the set of minimal elements of their intersection.
    We write this as $A \wedge B$.
\end{definition}

\begin{definition}[Join]
    The join of two prefix codes, $A$ and $B$, is the least upper bound of $A$ and $B$, i.e.,
    it is the set of maximal elements of their union.
    We write this as $A \vee B$.
\end{definition}

\begin{definition}[Element Refinement]
    We overload the comparison operators when one element is a string
    and the other is a complete prefix code,
    to mean that there is an element of the complete prefix code that satisfies the comparison operator.
    For example,
    $x \leq C$ means that $x$ is a prefix of some element of $C$,
    whereas $x > C$ means that $x$ is a proper extension of some element of $C$.
\end{definition}

\begin{proposition}
    The set of all properly terminated strings, $H$, is a complete prefix code.
\end{proposition}
\begin{proof}
    We first show that $H$ is a prefix code.
    We proceed by contradiction.
    Suppose there exist $h_1, h_2 \in H$ such that $h_1 < h_2$.
    Because $h_1$ is a strict prefix of $h_2$, it must be that $|h_1| < |h_2|$.
    Furthermore, the characters of $h_2$ must perfectly match $h_1$ up to index $|h_1|-1$. 
    Thus, 
    $$
    h_2[|h_1|-1] = h_1[|h_1|-1].
    $$
    Because $h_1 \in H$, it is properly terminated, meaning its final character is the stop character: $h_1[|h_1|-1] = \omega$.
    Therefore, $h_2[|h_1|-1] = \omega$.
    However, because $h_2 \in H$, the stop character can only appear at its final index $|h_2|-1$. This implies:
    $$
    |h_1|-1 = |h_2|-1 \implies |h_1| = |h_2|,
    $$
    which contradicts the strict prefix requirement $|h_1| < |h_2|$. Thus, no such pair $h_1, h_2$ can exist, and $H$ is a prefix code.


    We now show that $H$ is a complete prefix code.
    Let $x \in S$ be any string.
    We show this by cases constructively:
    \begin{enumerate}[label=(\alph*)]
        \item If $\omega$ is in $x$,
        then let $i$ be the index of its first occurrence. Then $x[:i+1] \in H$
        and $x[:i+1] \leq x$.
        \item If $\omega$ is not in $x$,
        then $x+\omega \in H$
        and $x < x+\omega$.
    \end{enumerate}
\end{proof}

\begin{definition}[Likelihood Function]
    A likelihood function is a mapping from properly terminated strings to non-negative real numbers,
    $L_n : H \to \mathbb{R}^+$.
\end{definition}

\begin{definition}[Prior Function]
\label{def:prior-function}
    A prior function is a mapping from properly terminated strings to non-negative real numbers,
    $P_m : H \to \mathbb{R}^+$,
    satisfying
    $$
    \sum_{h \in H} P_m(h) = 1
    $$
\end{definition}

\begin{definition}[Branch Prior Function]
\label{def:branch-prior-function}
    We define the branch prior function, $P^{br}_m(x)$, of an at most properly terminated string $x$,
    as,
    $$
    P^{br}_m(x) = \sum_{\substack{h \in H \\ h \geq x}} P_m(h)
    $$
\end{definition}
\textit{Terminology Note: } The branch prior function corresponds to our usual notion of a prior over
string prefixes, but we choose to name it explicitly as ``branch prior'' and to restrict our definition of the domain of
a ``prior function'' to properly terminated strings,
excluding their prefixes. We make this choice to keep a close correspondence
between the definitions of prior and likelihood functions.

\begin{definition}[Likelihood Sequence]
\label{def:likelihood-sequence}
    A likelihood sequence is a sequence of likelihood functions, $\{L_n\}$, with $L_0$ initialized to 1,
    i.e.,
    $$
    L_0(h) = 1 \quad \forall h \in H
    $$
\end{definition}

\begin{definition}[Prior Sequence]
    A prior sequence is a sequence of prior functions $\{P_n\}$.
\end{definition}

\begin{definition}[Delta Digest]
    A delta digest, $(C, \Delta)$, is a prefix code, $C$, and a mapping from that prefix code to non-negative real numbers, $\Delta$,
    i.e.,
    $$
    \Delta : C \to \mathbb{R}^+
    $$
\end{definition}

\begin{definition}[Prefix Code Truncation]
    The truncation of a string $x$ under a prefix code $C$ refers to the
    element $c \in C$ such that $c \leq x$.
    If no such element exists, then the truncation is undefined.
    We denote the truncation of $x$ under $C$ as $\lfloor x \rfloor_C$.
\end{definition}

\begin{definition}[Likelihood Delta Digest Sequence]
    The likelihood delta digest sequence corresponding to a likelihood sequence $\{L_n\}$ is a sequence of delta digests $\{(C^L_n, \Delta^L_n)\}$,
    that satisfies:
    $$
    \forall h \in H, L_n(h) = L_{n-1}(h) \Delta^L_n(\lfloor h \rfloor_{C^L_n})
    $$
    for the truncation operation to always be defined
    we require that $C^L_n \leq H$.
\end{definition}

\begin{definition}[Prior Delta Digest Sequence]
    This is defined identically,
    i.e.,
    the prior delta digest sequence corresponding to a prior sequence $\{P_n\}$ is a sequence of delta digests $\{(C^P_n, \Delta^P_n)\}$,
    that satisfies:
    $$
    \forall h \in H, P_n(h) = P_{n-1}(h) \Delta^P_n(\lfloor h \rfloor_{C^P_n})
    $$
    for the truncation operation to always be defined
    we require that $C^P_n \leq H$.
\end{definition}

\begin{lemma}[Likelihood Delta Product]
\label{lemma:likelihood-delta-product}
    $$
    L_N(h) =
    \prod_{1\leq i \leq N} \Delta^L_i(\lfloor h \rfloor_{C^L_i})
    $$
\end{lemma}
\begin{proof}
Fix any $h \in H$. By definition of a likelihood delta digest sequence, for each $i\in\{1,\dots,N\}$,
\[
L_i(h)=L_{i-1}(h)\,\Delta^L_i\!\left(\lfloor h\rfloor_{C^L_i}\right).
\]
Applying this recursively from $i=N$ down to $i=1$ gives
\[
L_N(h)
=
L_0(h)\prod_{1\le i\le N}\Delta^L_i\!\left(\lfloor h\rfloor_{C^L_i}\right).
\]
By definition of the likelihood sequence, $L_0(h)=1$, so
\[
L_N(h)=\prod_{1\le i\le N}\Delta^L_i\!\left(\lfloor h\rfloor_{C^L_i}\right),
\]
as claimed.
\end{proof}

\begin{lemma}[Eventually Constant Likelihoods]
\label{lemma:eventually-constant-likelihoods}
    Let $f \in \bigvee_{i=1}^N C^L_i$ be a node in the cumulative likelihood update frontier.
    Then every properly terminated descendant $h \in H$ of $f$ has the same likelihood at each time
    $n \leq N$. More precisely,
    $$
    \forall n \leq N, \forall h \in H,\ h \geq f \implies L_n(h) = \prod_{1\leq i \leq n} \Delta^L_i(\lfloor f \rfloor_{C^L_i})
    $$
\end{lemma}
\begin{proof}
    From lemma~\ref{lemma:likelihood-delta-product},
    $$
    L_n(h) = \prod_{1 \leq i \leq n} \Delta^L_i(\lfloor h \rfloor_{C^L_i}).
    $$
    We must show that $\lfloor h \rfloor_{C^L_i} = \lfloor f \rfloor_{C^L_i}$ for all $1\leq i \leq n$.
    
    If $f \in \bigvee_{i=1}^N C^L_i$, then for every $i \in \{1, \dots, n\}$, there exists some $c_i \in C^L_i$ such that $c_i \leq f$. Because $c_i$ is a prefix of $f$, it is exactly the truncation of $f$ under $C^L_i$, so $c_i = \lfloor f \rfloor_{C^L_i}$.

    By hypothesis, $h \geq f$. Since the prefix relation is transitive, $c_i \leq f$ and $f \leq h$ imply $c_i \leq h$. Because $C^L_i$ is a prefix code, $c_i$ is the unique element in $C^L_i$ that is a prefix of $h$. 
    Therefore, $\lfloor h \rfloor_{C^L_i} = c_i = \lfloor f \rfloor_{C^L_i}$.
    Substituting this into the product yields the result.
\end{proof}

\begin{definition}[Unnormalized Posterior Function]
    The unnormalized posterior function is a mapping
    from at most properly terminated strings to non-negative real numbers given by
    $$
    Z_{n,m}(x) = \sum_{\substack{h \in H \\ h \geq x}} L_n(h) P_m(h)
    $$
\end{definition}

\begin{proposition}
    Before any likelihood updates, the unnormalized posterior of the root node is 1:
    \begin{align*}
        Z_{0,m}(\epsilon) &= \sum_{\substack{h \in H \\ h \geq \epsilon}} L_0(h) P_m(h) \notag \\
        &= \sum_{h \in H} L_0(h) P_m(h) \notag \\
        &= \sum_{h \in H} 1 \cdot P_m(h) && \text{(by definition \ref{def:likelihood-sequence})} \\
        &= 1 && \text{(by definition \ref{def:prior-function})} \notag
    \end{align*}
\end{proposition}

\begin{lemma}[Posterior Equals Sum of Children]
\label{lemma:posterior-equals-sum-of-children}
    if $x$ is an unterminated string, then
    $$
    Z_{n,m}(x) = \sum_{\lambda \in \Lambda} Z_{n,m}(x+\lambda)
    $$
\end{lemma}
\begin{proof}
    By definition,
    $$
    Z_{n,m}(x) = \sum_{\substack{h \in H \\ h \geq x}} L_n(h) P_m(h).
    $$
    Since $x$ is an unterminated string, it does not contain the stop character. Because all strings in $H$ are properly terminated and therefore end with the stop character, $x \notin H$. Thus, any properly terminated string $h \in H$ that has $x$ as a prefix must be strictly longer than $x$ ($|h| > |x|$).

    Therefore, the character in $h$ immediately following the prefix $x$ must be some character $\lambda \in \Lambda$. We can partition the set of strings $\{h \in H \mid h \geq x\}$ into mutually disjoint subsets based on this next character $\lambda$:
    $$
    \{h \in H \mid h \geq x\} = \bigcup_{\lambda \in \Lambda} \{h \in H \mid h \geq x+\lambda\}.
    $$
    Because these subsets are disjoint, we can split the summation over them:
    \begin{align*}
        Z_{n,m}(x) &= \sum_{\lambda \in \Lambda} \sum_{\substack{h \in H \\ h \geq x+\lambda}} L_n(h) P_m(h) \\
        &= \sum_{\lambda \in \Lambda} Z_{n,m}(x+\lambda).
    \end{align*}
\end{proof}

We may now introduce the datastructure at the core of Dotter, the Bayesian Trie.
The Bayesian Trie maintains a calculation of the unnormalized posterior probability
while allowing for the lazy application of likelihood and prior updates.

\begin{definition}[Bayesian Trie Node]
    A Bayesian trie node $x$ associated with a string $s \in S$ is a data structure containing the tuple $(n, m, Z)$, accessed via fields:
    \begin{itemize}
        \item $x.n_Z \in \mathbb{N}$, the ``likelihood time'' of the posterior calculation of the node.
        \item $x.m_Z \in \mathbb{N}$, the ``prior time'' of the posterior calculation of the node.
        \item $x.Z \in \mathbb{R}^+$, a computed quantity which should be equal to the unnormalized posterior of the node evaluated at those times, i.e., $x.Z = Z_{x.n_Z, x.m_Z}(s)$.
    \end{itemize}
\end{definition}

\begin{definition}[Valid Node]
    A node, $x$, is called valid at time ($N_Z$, $M_Z$)
    if it satisfies one of the following two conditions:
    \begin{enumerate}
        \item \textbf{Constant Likelihood}: $x$ lies beyond
        the cumulative likelihood update frontier, i.e.,
        $x \geq \bigvee_{i=1}^{N_Z} C^L_i$
        \item \textbf{No Reweighting}:
        The likelihoods and the priors of descendants have changed by a constant factor
        since the node's time, i.e.,
        $x \geq \bigvee_{i=x.n_Z+1}^{N_Z} C^L_i$ and $x \geq \bigvee_{i=x.m_Z+1}^{M_Z} C^P_i$
    \end{enumerate}
\end{definition}

\begin{lemma}[Current Nodes are Valid]
\label{lemma:current-nodes-are-valid}
    A node is always valid at its own time.
    I.e.,
    $(x.n_Z, x.m_Z) = (N_Z, M_Z)$ implies that $x$ is valid at time $(N_Z, M_Z)$.
\end{lemma}
\begin{proof}
    Such a node satisfies the ``No Reweighting'' condition
    of validity. Because $(x.n_Z, x.m_Z) = (N_Z, M_Z)$, the two 
    joins are joins over empty sets and thus equal to the root node.
    Hence,
        $x \geq \bigvee_{i=x.n_Z+1}^{N_Z} C^L_i$ and $x \geq \bigvee_{i=x.m_Z+1}^{M_Z} C^P_i$
    .
\end{proof}

\begin{definition}[Bayesian Trie]
    A Bayesian Trie is a trie of Bayesian trie nodes
    along with a global tuple describing the current time,
    $(N_Z, M_Z)$.
\end{definition}

\begin{definition}[Valid Bayesian Trie]
    A Bayesian Trie is called valid, if all of its nodes are valid
    for the trie's global current time, $(N_Z, M_Z)$.
\end{definition}

\begin{definition}[Node Correctness]
    A node is ``correct'' if it correctly calculates the unnormalized posterior with respect to its local time,
    $$
    x.Z = Z_{x.n_Z, x.m_Z}(x)
    $$
\end{definition}

\begin{definition}[Bayesian Trie Correctness]
    The Bayesian trie is ``correct'' if all of its nodes are correct.
\end{definition}

We may now give the algorithm to advance a node's time.
This algorithm recalculates the unnormalized posterior
of a valid node, $x$, to a new local time, $(n'_Z, m'_Z)$.
\begin{algorithm}[H]
\caption{Advance Node Time}
\label{alg:advance-node-time}
\begin{algorithmic}[1]
\Require $x$, the node to update.
\Require $(x.n_Z, x.m_Z)$, the node's current time.
\Require $(n'_Z, m'_Z)$, the new time.
\Require $(N_Z, M_Z)$, the trie's current time.
\Require $x$ is valid at time $(N_Z, M_Z)$.
\Require $n'_Z \geq x.n_Z$ and $m'_Z \geq x.m_Z$.
\State $x.Z \gets
x.Z *
(P^{br}_{m'_Z}(x) / P^{br}_{x.m_Z}(x)) * 
\prod_{i=x.n_Z+1}^{n'_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i})
\label{alg:advance-node-time-recalculation}
$
\State $x.n_Z \gets n'_Z$
\State $x.m_Z \gets m'_Z$
\end{algorithmic}
\end{algorithm}


We also provide for advancing the trie to a new global time.

\begin{algorithm}[H]
\caption{Advance Trie Time}
\label{alg:advance-trie-time}
\begin{algorithmic}[1]
\Require Bayesian Trie $B$ is valid at its current time $(N_Z, M_Z)$.
\Require $(N_Z', M_Z')$, the new global time.
\State $B.N_Z \gets N_Z'$
\State $B.M_Z \gets M_Z'$
\State $F \gets \bigvee_{i=1}^{N_Z'} C^L_i \wedge \left(\bigvee_{i=N_Z+1}^{N_Z'} C^L_i \vee \bigvee_{i=M_Z+1}^{M_Z'} C^P_i\right)$
\Comment $x \geq F$ implies $x$ is valid at time $(N_Z', M_Z')$.
\State Run \texttt{AdvanceNodeTime} to update the time of
each node in this frontier to $(N_Z', M_Z')$.
\For{each node $x$ strictly within $F$, $x < F$, proceeding in reverse topological order}
    \State $x.Z \gets \sum_{\lambda \in \Lambda} (x+\lambda).\text{Z}$
    \label{alg:advance-trie-time-recalc-up-propagation}
    \State $x.n_Z \gets N_Z'$
    \State $x.m_Z \gets M_Z'$
\EndFor
\end{algorithmic}
\end{algorithm}

We now show that both algorithms preserve
the validity of the trie and its correctness.

\begin{theorem}[Advance Node Time Validity]
    The \texttt{AdvanceNodeTime} algorithm preserves the validity of the node.
\end{theorem}
\begin{proof}
    The ``constant likelihood'' condition depends only on the global time, not the node's local time,
    so updating the node's time does not affect whether this condition is satisfied.
    The ``no reweighting'' condition is weakened by increasing the node's time.
    I.e.,
    $$
    x \geq \bigvee_{i=x.n_Z+1}^{N_Z} C^L_i \implies x \geq \bigvee_{i=n'_Z+1}^{N_Z} C^L_i
    $$
    and,
    $$
    x \geq \bigvee_{i=x.m_Z+1}^{M_Z} C^P_i \implies x \geq \bigvee_{i=m'_Z+1}^{M_Z} C^P_i
    $$
    if $n'_Z \geq x.n_Z$ and $m'_Z \geq x.m_Z$.
\end{proof}

\begin{lemma}[Prior Delta Factorization]
\label{lemma:prior-delta-factorization}
    Let $m \leq m'$ and let $x$ be an at most properly terminated string satisfying
    $x \geq \bigvee_{i=m+1}^{m'} C^P_i$.
    Then
    \[
    P^{br}_{m'}(x)
    =
    P^{br}_{m}(x)
    \prod_{i=m+1}^{m'} \Delta^P_i(\lfloor x \rfloor_{C^P_i}).
    \]
\end{lemma}
\begin{proof}
    By the definition of a prior delta digest sequence,
    \[
    P_{m'}(h)
    =
    P_m(h)\prod_{i=m+1}^{m'}\Delta^P_i(\lfloor h \rfloor_{C^P_i})
    \qquad \forall h \in H.
    \]
    Since $x \geq \bigvee_{i=m+1}^{m'} C^P_i$, the same argument as in
    lemma~\ref{lemma:eventually-constant-likelihoods} shows that for every
    $h \geq x$ and every $i \in \{m+1,\dots,m'\}$,
    \[
    \lfloor h \rfloor_{C^P_i}=\lfloor x \rfloor_{C^P_i}.
    \]
    Hence, for all $h \geq x$,
    \[
    P_{m'}(h)
    =
    P_m(h)\prod_{i=m+1}^{m'}\Delta^P_i(\lfloor x \rfloor_{C^P_i}).
    \]
    Summing over all properly terminated descendants of $x$ gives
    \begin{align*}
    P^{br}_{m'}(x)
    &= \sum_{\substack{h \in H \\ h \geq x}} P_{m'}(h) \\
    &= \sum_{\substack{h \in H \\ h \geq x}}
    P_m(h)\prod_{i=m+1}^{m'}\Delta^P_i(\lfloor x \rfloor_{C^P_i}) \\
    &= \left(\sum_{\substack{h \in H \\ h \geq x}} P_m(h)\right)
    \prod_{i=m+1}^{m'}\Delta^P_i(\lfloor x \rfloor_{C^P_i}) \\
    &= P^{br}_{m}(x)\prod_{i=m+1}^{m'}\Delta^P_i(\lfloor x \rfloor_{C^P_i}),
    \end{align*}
    as claimed.
\end{proof}

\begin{corollary}[Prior Delta Quotient]
\label{corollary:prior-delta-quotient}
    Under the hypotheses of lemma~\ref{lemma:prior-delta-factorization}, if
    $P^{br}_{m}(x) > 0$, then
    \[
    \prod_{i=m+1}^{m'} \Delta^P_i(\lfloor x \rfloor_{C^P_i})
    =
    \frac{P^{br}_{m'}(x)}{P^{br}_{m}(x)}.
    \]
\end{corollary}

\begin{theorem}[Advance Node Time Correctness]
    The \texttt{AdvanceNodeTime} algorithm preserves the correctness of the node.
\end{theorem}
\begin{proof}
    By correctness before the update,
    $$
    x.Z = Z_{x.n_Z, x.m_Z}(x).
    $$
    We show that line~\ref{alg:advance-node-time-no-reweighting} changes this value to
    $Z_{n'_Z,m'_Z}(x)$ in each of the two validity cases.

    \textbf{Constant Likelihood Case:} Suppose
    $x \geq \bigvee_{i=1}^{N_Z} C^L_i$.
    Applying lemma~\ref{lemma:eventually-constant-likelihoods} with $f=x$ gives
    \begin{align*}
    x.Z
    &= Z_{x.n_Z, x.m_Z}(x) \\
    &= \sum_{\substack{h \in H \\ h \geq x}} P_{x.m_Z}(h) L_{x.n_Z}(h) \\
    &= \sum_{\substack{h \in H \\ h \geq x}} P_{x.m_Z}(h)
    \prod_{i=1}^{x.n_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i}) \\
    &= P^{br}_{x.m_Z}(x)\prod_{i=1}^{x.n_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i}).
    \end{align*}
    Therefore, after line~\ref{alg:advance-node-time-no-reweighting},
    \begin{align*}
    x.Z
    &=
    P^{br}_{x.m_Z}(x)\prod_{i=1}^{x.n_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i})
    \left(\frac{P^{br}_{m'_Z}(x)}{P^{br}_{x.m_Z}(x)}\right)
    \prod_{i=x.n_Z+1}^{n'_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i}) \\
    &= P^{br}_{m'_Z}(x)\prod_{i=1}^{n'_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i}) \\
    &= \left(\sum_{\substack{h \in H \\ h \geq x}} P_{m'_Z}(h)\right)
    \prod_{i=1}^{n'_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i}) \\
    &= \sum_{\substack{h \in H \\ h \geq x}} P_{m'_Z}(h)L_{n'_Z}(h) \\
    &= Z_{n'_Z,m'_Z}(x),
    \end{align*}
    where the third equality is by definition~\ref{def:branch-prior-function},
    the fourth is by lemma~\ref{lemma:eventually-constant-likelihoods},
    and the final equality is by definition of $Z_{n'_Z,m'_Z}$.

    \textbf{No Reweighting Case:} Suppose
    $x \geq \bigvee_{i=x.n_Z+1}^{N_Z} C^L_i$ and $x \geq \bigvee_{i=x.m_Z+1}^{M_Z} C^P_i$.
    For every $h \in H$ with $h \geq x$, the same truncation argument as in
    lemma~\ref{lemma:eventually-constant-likelihoods} gives
    \begin{align*}
    L_{n'_Z}(h)
    &= L_{x.n_Z}(h)\prod_{i=x.n_Z+1}^{n'_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i}), \\
    P_{m'_Z}(h)
    &= P_{x.m_Z}(h)\prod_{i=x.m_Z+1}^{m'_Z} \Delta^P_i(\lfloor x \rfloor_{C^P_i}).
    \end{align*}
    Hence
    \begin{align*}
    Z_{n'_Z,m'_Z}(x)
    &= \sum_{\substack{h \in H \\ h \geq x}} P_{m'_Z}(h)L_{n'_Z}(h) \\
    &= \sum_{\substack{h \in H \\ h \geq x}}
    P_{x.m_Z}(h)L_{x.n_Z}(h)
    \prod_{i=x.m_Z+1}^{m'_Z} \Delta^P_i(\lfloor x \rfloor_{C^P_i})
    \prod_{i=x.n_Z+1}^{n'_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i}) \\
    &= Z_{x.n_Z,x.m_Z}(x)
    \prod_{i=x.m_Z+1}^{m'_Z} \Delta^P_i(\lfloor x \rfloor_{C^P_i})
    \prod_{i=x.n_Z+1}^{n'_Z} \Delta^L_i(\lfloor x \rfloor_{C^L_i}).
    \end{align*}
    By corollary~\ref{corollary:prior-delta-quotient},
    $$
    \prod_{i=x.m_Z+1}^{m'_Z} \Delta^P_i(\lfloor x \rfloor_{C^P_i})
    =
    \frac{P^{br}_{m'_Z}(x)}{P^{br}_{x.m_Z}(x)}.
    $$
    Substituting this and using $x.Z = Z_{x.n_Z,x.m_Z}(x)$ shows that
    line~\ref{alg:advance-node-time-no-reweighting} sets
    $x.Z$ to $Z_{n'_Z,m'_Z}(x)$.
\end{proof}


\begin{lemma}[Frontier Calculation]
\label{lemma:frontier-calculation}
    If $F = \bigvee_{i=1}^{N_Z'} C^L_i \wedge \left(\bigvee_{i=N_Z+1}^{N_Z'} C^L_i \vee \bigvee_{i=M_Z+1}^{M_Z'} C^P_i\right)$,
    $x \geq F$,
    and $x$ is valid at time $(N_Z, M_Z)$,
    then $x$ is valid at time $(N_Z', M_Z')$.
\end{lemma}
\begin{proof}
    If $x \geq F$, then either
    $x \geq \bigvee_{i=1}^{N_Z'} C^L_i$ or both
    $x \geq \bigvee_{i=N_Z+1}^{N_Z'} C^L_i$ and
    $x \geq \bigvee_{i=M_Z+1}^{M_Z'} C^P_i$.
    The first case is exactly the ``Constant Likelihood'' branch in the definition of validity at time $(N_Z', M_Z')$.
    So we only need to consider the second case.

    The other assumption, that $x$ is valid at time $(N_Z, M_Z)$, also has two cases: either
    $x \geq \bigvee_{i=1}^{N_Z} C^L_i$ or
    $x \geq \bigvee_{i=x.n_Z+1}^{N_Z} C^L_i$ and $x \geq \bigvee_{i=x.m_Z+1}^{M_Z} C^P_i$.

    \textbf{Constant Likelihood for time $(N_Z, M_Z)$ Case:} Suppose $x$ is valid at time $(N_Z, M_Z)$ because it satisfies the constant likelihood condition, i.e., $x \geq \bigvee_{i=1}^{N_Z} C^L_i$.
    We may combine this with our previous result that
    $x \geq \bigvee_{i=N_Z+1}^{N_Z'} C^L_i$,
    in order to write,
    $x \geq \bigvee_{i=1}^{N_Z'} C^L_i$, which is the ``Constant Likelihood'' branch
    for validity at time $(N_Z', M_Z')$.

    \textbf{No Reweighting Case for time $(N_Z, M_Z)$ Case:} Suppose $x$ is valid at time $(N_Z, M_Z)$ because it satisfies the no reweighting condition, i.e., $x \geq \bigvee_{i=x.n_Z+2}^{N_Z} C^L_i$ and
    $x \geq \bigvee_{i=x.m_Z+1}^{M_Z} C^P_i$.
    We may combine these 
    with our previous result that
    $x \geq \bigvee_{i=N_Z+1}^{N_Z'} C^L_i$ and
    $x \geq \bigvee_{i=M_Z+1}^{M_Z'} C^P_i$,
    in order to write,
    $x \geq \bigvee_{i=x.n_Z+1}^{N_Z'} C^L_i$ and $x \geq \bigvee_{i=x.m_Z+1}^{M_Z'} C^P_i$,
    which is the ``No Reweighting'' condition for validity at time $(N_Z', M_Z')$.
\end{proof}

\begin{theorem}[Advance Trie Time Validity]
    We must show that after running \texttt{AdvanceTrieTime},
    the trie is valid at its new time, $(N_Z', M_Z')$.
\end{theorem}
\begin{proof}
    If $x > F$, then $x$ is unaffected by the algorithm and is valid at the new time by lemma~\ref{lemma:frontier-calculation}.
    Otherwise, $x \leq F$. All such nodes
    are updated to have the new time $(x.n_Z, x.m_Z) = (N_Z', M_Z')$.
    By lemma \ref{lemma:current-nodes-are-valid}, these nodes are valid at their new time.
\end{proof}

\begin{theorem}[Advance Trie Time Correctness]
    The \texttt{AdvanceTrieTime} algorithm preserves the correctness of the trie.
\end{theorem}
\begin{proof}
    We show this by induction on the trie.

    We are concerned with nodes, $x \leq F$, since nodes
    which are beyond the update boundary, $x > F$, are unaffected
    by the algorithm.

    At the start of the algorithm, all nodes are valid and correct.
    
    \textbf{Base Case: } If $x \in F$, the $x$ is valid and correct
    and we have already shown that running \texttt{AdvanceNodeTime} on $x$ preserves its validity and correctness.

    \textbf{Induction Step: } If $x < F$, then, because
    we process nodes in reverse topological order, by the induction hypothesis,
    all its immediate children are correct and have time $(N', M')$.
    Thus line \ref{alg:advance-trie-time-recalc-up-propagation} recalculates the unnormalized posterior of $x$ correctly
    by lemma \ref{lemma:posterior-equals-sum-of-children}.
\end{proof}



\section{Likelihood Tracking}
\label{sec:likelihood-tracking}
The preceding algorithm is correct, but we wish to avoid keeping all the
$\Delta^L_i$ in memory globally and the cost of calculating truncations, $\lfloor x \rfloor_{C^L_i}$.
To do so we introduce a field called ``unpushed likelihood'', $x.l$, which will be used 
to track the product of likelihood deltas as well
as a corresponding local ``likelihood tracking time'', $x.n_t$. We also augment our Bayesian Trie with a global ``likelihood tracking time'', $B.N_t$.

(Formally, these fields are independent of the global and local likelihood times
of the used in the preceding section, altough when we put the algorithms together,
they will be the same.)


We define our invariant, ``push correctness'':

\begin{definition}[Push Correctness]
\label{def:push-correctness}
    We say that a Bayesian trie $B$ is push correct for time $N_t$ if,
    every node has local likelihood tracking time at most $N_t$,
    and, for every node whose descendant likelihoods have changed by a constant factor,
    that factor is equal to the product of the ``unpushed likelihood'' fields of all of its ancestors (including itself).
    I.e.,
    \[
    \forall x,\; x.n_t \leq N_t
    \]
    and
    \[
    \forall x,\; x \geq \bigvee_{i=x.n_t+1}^{N_t} C^L_i \implies \prod_{y \leq x} y.l = \prod_{i = x.n_t+1}^{N_t} \Delta^L_i\bigl(\lfloor x \rfloor_{C^L_i}\bigr)
    \]
\end{definition}

This is invariant under two very simple algorithms:
\begin{algorithm}[H]
\caption{Push Likelihood}
\label{alg:push-likelihood}
\begin{algorithmic}[1]
\Require Bayesian Trie $B$, Node $x$
\Require $B$ is push correct for time $B.N_t$.
\Require $\forall a < x, a.l = 1$
\Comment{$x$ does not have ancestors with unpushed likelihood}
\State $y.l \gets y.l * x.l  \quad \forall y \in x.\text{children}$
\State $x.l \gets 1$
\State $x.n_t \gets B.N_t$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Apply Likelihood Delta}
\label{alg:apply-likelihood-delta}
\begin{algorithmic}[1]
\Require Bayesian Trie $B$, Node $x$
\Require $B$ is push correct for time $B.N_t$.
\For{each node $x \in C^L_{B.N_t+1}$}
    \State $x.l \gets x.l * \Delta^L_{B.N_t+1}(x)$
\EndFor
\State $B.N_t \gets B.N_t+1$
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Push Likelihood Correctness]
    Algorithm~\ref{alg:push-likelihood} preserves the push correctness of the trie.
\end{theorem}
\begin{proof}
    Let $N = B.N_t$, and let $B'$ be the trie after the algorithm is applied.
    We show that the defining equality of push correctness still holds for every node $z$.

    First consider $z \neq x$.
    If $z \not> x$, then none of the ancestors of $z$ are modified by the algorithm,
    so $\prod_{y \leq z} y.l$ is unchanged.
    If $z > x$, then the algorithm removes the factor $x.l$ from $x$ and multiplies it
    into each child of $x$.
    Along the ancestor chain of $z$, exactly one child of $x$ occurs, so the product
    $\prod_{y \leq z} y.l$ is again unchanged.
    In either subcase, $z.n_t$ is unchanged and $B'.N_t=N$, so the right-hand side
    of Definition~\ref{def:push-correctness} is unchanged as well.
    Since $B$ was push correct before the algorithm, the equality continues to hold for $z$ in $B'$.

    Now consider $z = x$.
    After the algorithm, $x.l = 1$ and $x.n_t = N$.
    By the precondition, every strict ancestor $a < x$ satisfies $a.l = 1$.
    Therefore
    \[
    \prod_{y \leq x} y.l = 1.
    \]
    On the other hand, because $x.n_t = B'.N_t = N$, the product on the right-hand side
    of Definition~\ref{def:push-correctness} is an empty product, hence also equal to $1$.
    Thus the equality holds for $x$ as well.

    Therefore $B'$ is push correct for time $N$.
\end{proof}

\begin{theorem}[Apply Likelihood Delta Correctness]
    Algorithm~\ref{alg:apply-likelihood-delta} preserves the push correctness of the trie.
\end{theorem}
\begin{proof}
    Let $N$ be the value of $B.N_t$ before the algorithm, and let $B'$ be the trie after the algorithm.
    Then $B'.N_t = N+1$.

    Fix a node $z$ such that
    \[
    z \geq \bigvee_{i=z.n_t+1}^{N+1} C^L_i.
    \]
    We must show that
    \[
    \prod_{y \leq z} y.l
    =
    \prod_{i=z.n_t+1}^{N+1} \Delta^L_i\bigl(\lfloor z \rfloor_{C^L_i}\bigr)
    \]
    holds in $B'$.

    Since $z \geq \bigvee_{i=z.n_t+1}^{N+1} C^L_i$, in particular $z \geq C^L_{N+1}$.
    Hence $\lfloor z \rfloor_{C^L_{N+1}}$ is defined and is an ancestor of $z$.
    Because $C^L_{N+1}$ is a prefix code, this is the unique node of $C^L_{N+1}$
    on the ancestor chain of $z$.

    The algorithm multiplies $u.l$ by $\Delta^L_{N+1}(u)$ for each $u \in C^L_{N+1}$.
    Therefore, along the ancestor chain of $z$, exactly one factor is introduced, namely
    \[
    \Delta^L_{N+1}\bigl(\lfloor z \rfloor_{C^L_{N+1}}\bigr).
    \]
    So in $B'$ we have
    \[
    \prod_{y \leq z} y.l
    =
    \left(\prod_{y \leq z} y.l\right)_B
    \Delta^L_{N+1}\bigl(\lfloor z \rfloor_{C^L_{N+1}}\bigr).
    \]

    Since $B$ was push correct for time $N$,
    \[
    \left(\prod_{y \leq z} y.l\right)_B
    =
    \prod_{i=z.n_t+1}^{N} \Delta^L_i\bigl(\lfloor z \rfloor_{C^L_i}\bigr).
    \]
    Substituting gives
    \[
    \prod_{y \leq z} y.l
    =
    \left(\prod_{i=z.n_t+1}^{N} \Delta^L_i\bigl(\lfloor z \rfloor_{C^L_i}\bigr)\right)
    \Delta^L_{N+1}\bigl(\lfloor z \rfloor_{C^L_{N+1}}\bigr)
    =
    \prod_{i=z.n_t+1}^{N+1} \Delta^L_i\bigl(\lfloor z \rfloor_{C^L_i}\bigr).
    \]
    This is exactly the required equality, so $B'$ is push correct for time $N+1$.
\end{proof}

token prefixes, such as $\left[\texttt{`the'},\, \texttt{` dot'}\right]$, $\left[\texttt{`the'},\, \texttt{` d'}\right]$, and $\left[\texttt{`the'}\right]$.
For each token prefix, the literal prefix
can be generated from multiple possible terminal tokens. For example, given the token prefix $\left[\texttt{`the'},\, \texttt{` dot'}\right]$,
the literal prefix is compatible with either of the terminal tokens `\texttt{ter}' or `\texttt{tering}'.

In this section, we formalize tokenization,
introduce a key property of byte-pair encoders called boundary sufficiency,
and prove theorem~\ref{theorem:token-prior-path-summation} which allows us to compute the prior of a literal prefix
by summing over all token sequences that pass through it.

\textit{Terminology Note: } It is helpful to make three kinds of distinctions: (1) between sets and their elements,
(2) between sequences (either strings or token sequences) and their elements, and (3) between characters and tokens. We will choose to 
use uppercase letters for sets, Greek letters for individual characters or tokens, and bold font for token sequences.

\begin{definition}[Vocabulary]
    A vocabulary is a finite set.
    We will use the notation $\mathbf{\Lambda}$ to represent our vocabulary.
\end{definition}

\begin{definition}[Token]
    A token is an element of a vocabulary.
\end{definition}

\begin{definition}[Token Sequence]
    A token sequence is a sequence of tokens.
\end{definition}

Throughout this chapter we will use the notation $\boldsymbol{\Lambda}$ to refer to our vocabulary. We will require that
our vocabulary contain a special ``stop'' token, denoted, $\boldsymbol{\omega}$.
The set of all token sequences will be denoted $\boldsymbol{S}$.


\begin{definition}[Properly Terminated Token Sequence]
    A token sequence is properly terminated if and only if it ends with the stop token, with all
    preceding tokens not being the stop token. I.e.,
    \[
    \forall i \quad (i = |\boldsymbol{a}| - 1 \iff \boldsymbol{a}[i] = \boldsymbol{\omega})
    \]
\end{definition}

Analogously to the string case, we will use the notation $\boldsymbol{H}$ to
represent the set of all properly terminated token sequences.

\begin{definition}[At Most Properly Terminated Token Sequence]
    A token sequence, $\boldsymbol{a} \in \boldsymbol{S}$, is at most properly terminated if and only if it is either properly
    terminated or contains no stop token, i.e.,
    $\boldsymbol{a} \in \boldsymbol{H}$ or $\not\exists i \;
    \boldsymbol{a}[i] = \boldsymbol{\omega}$.
\end{definition}

We will use the symbol $\mathbf{A}$ to represent the set of all admissible token sequences.

\begin{definition}[Spelling Function]
    The spelling function, $\rho$, maps a token to a string
    $$
    \rho: \boldsymbol{\Lambda} \to \boldsymbol{S}
    $$
    we require that,
    $$
    \rho(\boldsymbol{\omega}) = \omega
    $$
\end{definition}

\begin{definition}[Literalization Function]
    The literalization function, $T^{-1}$, maps a token sequence to a string by concatenating their spellings.
    That is,
    \[
    T^{-1}(\mathbf{a}) = \rho(\mathbf{a}[0])\;\rho(\mathbf{a}[1])\;\cdots\;\rho(\mathbf{a}[-1])
    \]
    where juxtaposition denotes string concatenation.
\end{definition}

\begin{definition}[Tokenization Function]
    A tokenization function is a mapping from strings to token sequences,
    $T: S \to \mathbf{S}$
    that is inverted by literalization, i.e.,
    $$
    T^{-1}(T(x)) = x \quad \forall x \in S
    $$
    (but the converse will not usually hold, i.e., different token sequences may correspond to the same string.)
    We also require that the tokenization function maps
    properly terminated strings to properly terminated token sequences,
    $$
    T: H \to \mathbf{H}
    $$
    so in particular the final stop character of a properly terminated string
    tokenizes as the stop token.
\end{definition}

\begin{definition}[Canonical Token Sequence]
    A token sequence $\mathbf{a}$ is canonical if and only if re-tokenizing its
    literalization yields the same token sequence:
    \[
    T(T^{-1}(\mathbf{a})) = \mathbf{a}.
    \]
\end{definition}

We will use the symbol $\mathbf{C}$ to represent the set of all canonical token sequences.


\begin{proposition}
\label{prop:tokenizations-are-canonical}
    For every string $x$, the token sequence $T(x)$ is canonical.
\end{proposition}
\begin{proof}
    By definition,
    $$
    T(T^{-1}(T(x))) = T(x).
    $$
\end{proof}

\begin{definition}[Admissible Token Sequence]
    A token sequence is admissible if and only if it is canonical and at most properly terminated.
\end{definition}

\begin{definition}[String versus Token Sequence Comparison]
    Since literalization is a well defined function, we compare token sequences and strings,
    by first literalizing the token sequence to a string.
    For example we can write, $\mathbf{a} \leq x$,
    to mean, $T^{-1}(\mathbf{a}) \leq x$. It does \textit{not} mean that $\mathbf{a} \leq T(x)$.
\end{definition}

\begin{definition}[Token Sequence String Subtraction]
    We can perform subtraction between a string and a token sequence by first literalizing the token sequence to a string and then applying definition~\ref{def:string-subtraction}.
\end{definition}

\begin{definition}[Token Sequence versus Complete Prefix Code Comparison]
    We also compare token sequences and complete prefix codes by first literalizing the token
    sequence to a string. We write $\mathbf{a} \leq C$ to mean $T^{-1}(\mathbf{a}) \leq C$,
    and $\mathbf{a} > C$ to mean $T^{-1}(\mathbf{a}) > C$.
\end{definition}

\begin{definition}[Token Sequence versus Token Sequence Comparison]
    We compare token sequences as sequences of symbols, not as literalized strings.
    That is, $\mathbf{a} \leq \mathbf{b}$ means that
    $\exists i, \mathbf{a} = \mathbf{b}[:i]$,
    it does \emph{not} mean that $T^{-1}(\mathbf{a}) \leq T^{-1}(\mathbf{b})$.
\end{definition}


\begin{definition}[Boundary Sufficiency]
    The boundary sufficiency property of a tokenization function states that every contiguous
    subsequence of a canonical token sequence remains canonical when retokenized in isolation.
    Formally, a tokenization function $T$ has boundary sufficiency if for every canonical token
    sequence $\mathbf{a} \in \mathbf{C}$ and every $0 \leq i \leq j \leq |\mathbf{a}|$,
    $$
    T(T^{-1}(\mathbf{a}[i:j])) = \mathbf{a}[i:j].
    $$
\end{definition}

Henceforth, we will always assume that our tokenization function has boundary sufficiency.
This is because all byte-pair encoders have this property.

\begin{proposition}[Token-sequence prefixes of a tokenization are canonical]
\label{prop:tokenization-prefixes-are-canonical}
    If $\mathbf{b} \leq T(x)$, then $\mathbf{b} \in \mathbf{C}$.
\end{proposition}
\begin{proof}
    Since $T(x) \in \mathbf{C}$ by proposition~\ref{prop:tokenizations-are-canonical} and $\mathbf{b} \leq T(x)$, there exists $j \leq |T(x)|$ such that
    $\mathbf{b} = T(x)[:j]$. Applying boundary sufficiency to the canonical token sequence $T(x)$
    with indices $0$ and $j$ gives
    $$
    T(T^{-1}(\mathbf{b}))
    =
    T(T^{-1}(T(x)[:j]))
    =
    T(x)[:j]
    =
    \mathbf{b},
    $$
    so $\mathbf{b} \in \mathbf{C}$.
\end{proof}

We can now formalize a token-based language model.

\begin{definition}[Conditional Token Prior Function]
\label{def:conditional-token-prior-function}
    Our conditional token prior function tells us the conditional probability of a token
    given a token sequence. It is a mapping
    $$
    \mathbf{Q} : \mathbf{\Lambda}^* \times \mathbf{\Lambda} \to \mathbb{R}^+
    $$
    written as $\mathbf{Q}(\boldsymbol{\tau} \mid \mathbf{a})$,
    where,
    $$
    \forall \mathbf{a} \in \mathbf{\Lambda}^*, \sum_{\boldsymbol{\tau} \in \mathbf{\Lambda}} \mathbf{Q}(\boldsymbol{\tau} \mid \mathbf{a}) = 1.
    $$
    We also require canonical support:
    \[
    \mathbf{Q}(\boldsymbol{\tau} \mid \mathbf{a}) = 0
    \qquad
    \text{whenever } \mathbf{a} \in \mathbf{A} \text{ and } \mathbf{a}+\boldsymbol{\tau} \notin \mathbf{A}.
    \]
    We also require almost-sure termination: for every admissible token sequence
    $\mathbf{a} \in \mathbf{A}\setminus\mathbf{H}$,
    \[
    \sum_{\mathbf{s} \in \mathbf{H}}
    \prod_{i < |\mathbf{s}|} \mathbf{Q}(\mathbf{s}[i] \mid \mathbf{a}+\mathbf{s}[:i])
    = 1.
    \]
\end{definition}

\textit{Explanatory Note: } The almost-sure termination condition is an assumption on the
conditional token prior, not a lemma. Local normalization of $\mathbf{Q}(\boldsymbol{\tau}\mid\mathbf{a})$
only guarantees that the next token is sampled from a probability distribution; by itself it does
not imply that the process eventually emits the stop token with probability $1$.

\begin{definition}[Conditional Token Prior Function Sequence]
    A conditional token prior function sequence is a sequence of conditional token prior functions,
    $ \{ \mathbf{Q}_n \} $.
\end{definition}

\begin{definition}[Token Prior Function]
    A token prior function is a mapping from properly terminated token sequences to
    non-negative real numbers,
    \[
    \mathbf{P}_m : \mathbf{H} \to \mathbb{R}^+,
    \]
    satisfying
    \[
    \sum_{\mathbf{h} \in \mathbf{H}} \mathbf{P}_m(\mathbf{h}) = 1.
    \]
\end{definition}

\begin{definition}[Token Branch Prior Function]
\label{def:token-branch-prior-function}
    The token branch prior of a token sequence $\mathbf{a}$ is
    \[
    \mathbf{P}^{br}_m(\mathbf{a})
    :=
    \sum_{\substack{\mathbf{h} \in \mathbf{H} \\ \mathbf{h} \geq \mathbf{a}}}
    \mathbf{P}_m(\mathbf{h}).
    \]
\end{definition}

\begin{definition}[Induced Token Prior]
\label{def:induced-token-prior}
    Given a conditional token prior function $\mathbf{Q}_m$, we define the induced token
    prior on properly terminated token sequences by
    \[
    \mathbf{P}_m(\mathbf{h})
    :=
    \prod_{i < |\mathbf{h}|} \mathbf{Q}_m(\mathbf{h}[i] \mid \mathbf{h}[:i]).
    \]
\end{definition}

\begin{proposition}[Induced Token Prior Is a Token Prior]
    The induced token prior is a token prior function.
\end{proposition}
\begin{proof}
    By definition, $\mathbf{P}_m : \mathbf{H} \to \mathbb{R}^+$.
    It remains to show that
    \[
    \sum_{\mathbf{h} \in \mathbf{H}} \mathbf{P}_m(\mathbf{h}) = 1.
    \]
    Since the empty token sequence is admissible and not properly terminated, the
    almost-sure termination assumption gives
    \[
    \sum_{\mathbf{h} \in \mathbf{H}}
    \prod_{i < |\mathbf{h}|} \mathbf{Q}_m(\mathbf{h}[i] \mid \mathbf{h}[:i])
    = 1.
    \]
    By definition~\ref{def:induced-token-prior}, the summand is exactly
    $\mathbf{P}_m(\mathbf{h})$, so the claim follows.
\end{proof}

\begin{lemma}[Token Branch Prior Product Formula]
\label{lemma:token-branch-prior-product}
    For every admissible token sequence $\mathbf{a} \in \mathbf{A}$,
    \[
    \mathbf{P}^{br}_m(\mathbf{a})
    =
    \prod_{i < |\mathbf{a}|} \mathbf{Q}_m(\mathbf{a}[i] \mid \mathbf{a}[:i]).
    \]
\end{lemma}
\begin{proof}
    We split into two cases.

    If $\mathbf{a}\in\mathbf{H}$, then $\mathbf{a}$ is already properly terminated.
    No properly terminated token sequence can be a strict extension of $\mathbf{a}$,
    since that would place the stop token before the final index. Therefore
    $\mathbf{a}$ is the unique properly terminated descendant of itself, so
    \[
    \mathbf{P}^{br}_m(\mathbf{a}) = \mathbf{P}_m(\mathbf{a}).
    \]
    By definition~\ref{def:induced-token-prior}, this is exactly
    \[
    \prod_{i < |\mathbf{a}|} \mathbf{Q}_m(\mathbf{a}[i] \mid \mathbf{a}[:i]).
    \]

    Now suppose $\mathbf{a} \in \mathbf{A}\setminus\mathbf{H}$.
    Every properly terminated token sequence $\mathbf{h} \geq \mathbf{a}$ can be written
    uniquely as $\mathbf{h}=\mathbf{a}+\mathbf{s}$ where $\mathbf{s}\in\mathbf{H}$.
    Therefore,
    \begin{align*}
    \mathbf{P}^{br}_m(\mathbf{a})
    &= \sum_{\substack{\mathbf{h} \in \mathbf{H} \\ \mathbf{h} \geq \mathbf{a}}} \mathbf{P}_m(\mathbf{h}) \\
    &= \sum_{\mathbf{s} \in \mathbf{H}} \mathbf{P}_m(\mathbf{a}+\mathbf{s}) \\
    &= \sum_{\mathbf{s} \in \mathbf{H}}
    \left(
        \prod_{i < |\mathbf{a}|} \mathbf{Q}_m(\mathbf{a}[i] \mid \mathbf{a}[:i])
    \right)
    \left(
        \prod_{i < |\mathbf{s}|} \mathbf{Q}_m(\mathbf{s}[i] \mid \mathbf{a}+\mathbf{s}[:i])
    \right) \\
    &=
    \left(
        \prod_{i < |\mathbf{a}|} \mathbf{Q}_m(\mathbf{a}[i] \mid \mathbf{a}[:i])
    \right)
    \sum_{\mathbf{s} \in \mathbf{H}}
    \prod_{i < |\mathbf{s}|} \mathbf{Q}_m(\mathbf{s}[i] \mid \mathbf{a}+\mathbf{s}[:i]) \\
    &=
    \prod_{i < |\mathbf{a}|} \mathbf{Q}_m(\mathbf{a}[i] \mid \mathbf{a}[:i]),
    \end{align*}
    where the final step is the almost-sure termination assumption in
    definition~\ref{def:conditional-token-prior-function}.
\end{proof}

Henceforth we will study prior functions that are derived from token
priors induced from conditional token priors by the relation,
$$
P_n(h) = \mathbf{P}_n(T(h)).
$$

We can now state our first result

\begin{theorem}[Token Prior Path Summation]
\label{theorem:token-prior-path-summation}
    The branch prior of a string $a$, is the sum of the token branch priors of all
    token sequences that pass through $a$.
    $$
    P^{br}(a)=
    \begin{cases}
        1, & a=\epsilon,\\[4pt]
        \displaystyle
        \sum_{\substack{\mathbf{b} \in \mathbf{A} \\ \mathbf{b} < a}} 
        \mathbf{P}^{br}(\mathbf{b})
        \sum_{\substack{\boldsymbol{\tau} \in \mathbf{\Lambda} \\ a \leq \mathbf{b} + \boldsymbol{\tau}}}
        \mathbf{Q}(\boldsymbol{\tau} \mid \mathbf{b}), & a \neq \epsilon.
    \end{cases}
    $$
\end{theorem}
\begin{proof}
    We prove the two cases separately.

    If $a=\epsilon$, then by Definition~\ref{def:branch-prior-function},
    $$
    P^{br}(\epsilon)=\sum_{\substack{h\in H\\ h\ge \epsilon}}P(h)=\sum_{h\in H}P(h)=1.
    $$

    Now let $a\neq\epsilon$. Again from Definition~\ref{def:branch-prior-function},
    $$
    P^{br}(a)=\sum_{\substack{h\in H\\ h\ge a}}P(h).
    $$

    For each $h\ge a$, write $\mathbf{c}:=T(h)$. Since $\mathbf{c}\ge a$,
    there exists a unique smallest $j$ such that
    $a\le \mathbf{c}[:j+1]$.
    Define $\mathbf{b}:=\mathbf{c}[:j]$ and $\boldsymbol{\tau}:=\mathbf{c}[j]$.
    By minimality of $j$, we have
    $$
    \mathbf{b}<a\le \mathbf{b}+\boldsymbol{\tau}.
    $$
    So each $h\ge a$ determines a unique pair $(\mathbf{b},\boldsymbol{\tau})$ with those inequalities.

    Grouping the sum over $h$ by these pairs gives
    $$
    P^{br}(a)=
    \sum_{\substack{\mathbf{b}\in\mathbf{A}\\\mathbf{b}<a}}
    \;\;
    \sum_{\substack{\boldsymbol{\tau}\in\mathbf{\Lambda}\\a\le \mathbf{b}+\boldsymbol{\tau}}}
    \;\;
    \sum_{\substack{h\in H:\\ (\mathbf{b}+\boldsymbol{\tau}) \leq T(h)}}
    P(h).
    $$

    By the defining relation $P_m(h)=\mathbf{P}_m(T(h))$, the innermost sum is
    \[
    \sum_{\substack{\mathbf{h}\in\mathbf{H}\\ \mathbf{h}\geq \mathbf{b}+\boldsymbol{\tau}}}
    \mathbf{P}_m(\mathbf{h}),
    \]
    which is exactly $\mathbf{P}^{br}(\mathbf{b}+\boldsymbol{\tau})$ by
    definition~\ref{def:token-branch-prior-function}. By
    lemma~\ref{lemma:token-branch-prior-product},
    $$
    \mathbf{P}^{br}(\mathbf{b}+\boldsymbol{\tau})
    =\mathbf{P}^{br}(\mathbf{b})\,\mathbf{Q}(\boldsymbol{\tau}\mid\mathbf{b}).
    $$
    Substituting yields
    $$
    P^{br}(a)=
    \sum_{\mathbf{b}\in\mathbf{A},\,\mathbf{b}<a}\mathbf{P}^{br}(\mathbf{b})
    \sum_{\boldsymbol{\tau}\in\mathbf{\Lambda},\,a\le \mathbf{b}+\boldsymbol{\tau}}\mathbf{Q}(\boldsymbol{\tau}\mid\mathbf{b}),
    $$
    as claimed.
\end{proof}


\section{Prior Tracking}
\label{sec:prior-tracking}
We now provide an algorithm to implement theorem~\ref{theorem:token-prior-path-summation}.
Thus it suffices to compute $P^{br}_{M'_P}(x)$ on the valid frontier.
We now formalize a finite dynamic program that does exactly this.

\begin{definition}[Token Fan]
\label{def:token-fan}
    Let $m$ be a prior time, let $\mathbf{b} \in \mathbf{A}$ be an admissible token sequence,
    and let $x$ be an at most properly terminated string.
    The token fan of $x$ from context $\mathbf{b}$ at time $m$ is
    \[
    \Phi_m(\mathbf{b}, x)
    :=
    \sum_{\boldsymbol{\tau}\in\mathbf{\Lambda},\,x\le \mathbf{b}+\boldsymbol{\tau}}
    \mathbf{Q}_m(\boldsymbol{\tau}\mid\mathbf{b}).
    \]
\end{definition}

\begin{definition}[Token Ancestor String]
    \label{def:token-ancestor}
    For a non-empty string $x$, we define its token ancestor string by
    \[
    \pi(x) := T^{-1}(T(x)[:-1]).
    \]
\end{definition}

\begin{definition}[String-Prefix Context]
\label{def:string-prefix-context}
    For a string $x$ and a character index $i \leq |x|$, we define the
    string-prefix context
    \[
    \kappa_x(i) := T(x[:i]).
    \]
    (and for convenience, we allow this notation for negative indices too).
\end{definition}

\textit{Explanatory Note: } The sum for a branch prior runs over \emph{string}
ancestors of $x$, not merely over token ancestors of $x$ in its own tokenization.
For each strict string prefix $x[:i]$, we re-tokenize that shorter string to obtain
the context $\kappa_x(i)$. In general, $\kappa_x(i)$ need not be a prefix of $T(x)$.
This is exactly why algorithm~\ref{alg:compute-branch-prior} must sum over all
strict string ancestors.

\begin{lemma}[Token Prefix Retokenization]
\label{lemma:token-prefix-retokenization}
    For every string $x$ and every $j \leq |T(x)|$,
    \[
    T(T^{-1}(T(x)[:j])) = T(x)[:j].
    \]
\end{lemma}
\begin{proof}
    Since $T(x) \in \mathbf{C}$, the claim follows immediately from boundary sufficiency
    applied to the canonical token sequence $T(x)$ with indices $0$ and $j$.
\end{proof}

\begin{lemma}[Nonadmissible Token Branch Priors Vanish]
\label{lemma:nonadmissible-token-branch-prior-vanishes}
    If a token sequence $\mathbf{a}$ is not admissible, then
    \[
    \mathbf{P}^{br}_m(\mathbf{a}) = 0.
    \]
\end{lemma}
\begin{proof}
    If $\mathbf{a}$ is not at most properly terminated, then no properly terminated token
    sequence can extend $\mathbf{a}$, since that would preserve an internal stop token.
    Hence the index set in definition~\ref{def:token-branch-prior-function} is empty, so
    $\mathbf{P}^{br}_m(\mathbf{a}) = 0$.

    Otherwise, $\mathbf{a}$ is at most properly terminated but not canonical.
    Let $j$ be the least index such that $\mathbf{a}[:j+1]$ is not canonical.
    Then $\mathbf{a}[:j]$ is canonical, and because $\mathbf{a}$ is at most properly
    terminated, the sequence $\mathbf{a}[:j+1]$ is not admissible. By admissible support,
    \[
    \mathbf{Q}_m(\mathbf{a}[j] \mid \mathbf{a}[:j]) = 0.
    \]
    Every properly terminated descendant $\mathbf{h} \geq \mathbf{a}$ has the same prefix
    $\mathbf{a}[:j+1]$, so its induced token prior contains the same zero factor.
    Therefore $\mathbf{P}_m(\mathbf{h}) = 0$ for every such descendant, and hence
    \[
    \mathbf{P}^{br}_m(\mathbf{a}) = 0.
    \]
\end{proof}

\begin{theorem}[String-Ancestor Reindexing]
\label{theorem:string-ancestor-reindexing}
    For every non-empty at most properly terminated string $x$,
    \[
    P^{br}_m(x)
    =
    \sum_{i=0}^{|x|-1}
    \mathbf{P}^{br}_m(\kappa_x(i)) \, \Phi_m(\kappa_x(i), x).
    \]
\end{theorem}
\begin{proof}
    By theorem~\ref{theorem:token-prior-path-summation},
    \[
    P^{br}_m(x)
    =
    \sum_{\mathbf{b}\in\mathbf{A},\,\mathbf{b}<x}
    \mathbf{P}^{br}_m(\mathbf{b}) \, \Phi_m(\mathbf{b},x).
    \]

    We now reindex this sum by the literal prefix
    \[
    s := T^{-1}(\mathbf{b}).
    \]
    Since $\mathbf{b} \in \mathbf{A}$, in particular $\mathbf{b}$ is canonical, so
    \[
    \mathbf{b} = T(T^{-1}(\mathbf{b})) = T(s),
    \]
    so $\mathbf{b} = \kappa_x(|s|)$. Since $s < x$, this index satisfies
    $|s| < |x|$.

    Thus the admissible contexts are in one-to-one
    correspondence with the strict string prefixes $x[:i]$ for $0 \leq i < |x|$,
    via $\mathbf{b} = \kappa_x(i) = T(x[:i])$. Substituting this reindexing into
    the path-summation formula yields
    \[
    P^{br}_m(x)
    =
    \sum_{i=0}^{|x|-1}
    \mathbf{P}^{br}_m(\kappa_x(i)) \, \Phi_m(\kappa_x(i), x),
    \]
    as claimed.
\end{proof}


We provide two short algorithms to compute the priors.
The essential thing is to know the ``token branch prior'', written $x.\mathbf{P}$,
of the ancestors
of a node before computing its branch prior, $x.P$.
We augment nodes with times tracking when these calculations 
are valid, $x.m_P$ and $x.m_\mathbf{P}$.
Correspondingly, we use global times $M_P$ and $M_\mathbf{P}$ for the trie.
In the present algorithms these are always updated in sync, so $M_P = M_\mathbf{P}$,
but it is clearer to distinguish them notationally.

Unlike our likelihood tracking, and our core algorithm, which both
lazily reuse calculations across iterations, this section requires
us to rerun the prior calculations from the root on each update.
This makes the presentation simple.

\begin{algorithm}[H]
\caption{Compute Token Branch Prior}
\label{alg:compute-token-branch-prior}
\begin{algorithmic}[1]
\Require Bayesian Trie $B$, Node $x$, New Time $m$
\Require Every node in $B$ stores correct prior values for its recorded times.
\Require $x = \epsilon$ or $\pi(x).m_\mathbf{P} = m$ \Comment{The token ancestor of $x$ already has the new time.}
\If{$x = \epsilon$}
    \State $x.\mathbf{P} \gets 1$
\Else
    \State $x.\mathbf{P} \gets \pi(x).\mathbf{P} * \mathbf{Q}_m(T(x)[-1] \mid T(x)[:-1])$
\EndIf
\State $x.m_\mathbf{P} \gets m$
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{Compute Branch Prior}
\label{alg:compute-branch-prior}
\begin{algorithmic}[1]
\Require Bayesian Trie $B$, Node $x$, New Time $m$
\Require Every node in $B$ stores correct prior values for its recorded times.
\Require $(x[:i]).m_\mathbf{P} = m \quad \forall i < |x|$ \Comment{All string ancestors of $x$ already have calculated the token branch prior at the new time.}
\State $x.P \gets \sum_{i=0}^{|x|-1} (x[:i]).\mathbf{P} * \Phi_m(\kappa_x(i), x)$  \Comment{Theorem \ref{theorem:string-ancestor-reindexing}.}
\State $x.m_P \gets m$
\end{algorithmic}
\end{algorithm}

We now show the correctness of these two algorithms.

\begin{theorem}[Compute Token Branch Prior Correctness]
    Algorithm~\ref{alg:compute-token-branch-prior} correctly computes the token branch prior of a node.
\end{theorem}
\begin{proof}
    We must show that after the algorithm runs,
    \[
    x.\mathbf{P} = \mathbf{P}^{br}_m(T(x)).
    \]
    There are two cases.


    If $x=\epsilon$, the algorithm sets $x.\mathbf{P}\gets 1$.
    Also $T(\epsilon)=\epsilon$, so it suffices to show that
    \[
    \mathbf{P}^{br}_m(\epsilon)=1.
    \]
    By definition~\ref{def:token-branch-prior-function},
    \[
    \mathbf{P}^{br}_m(\epsilon)
    =
    \sum_{\mathbf{h}\in\mathbf{H}} \mathbf{P}_m(\mathbf{h}),
    \]
    which is equal to $1$ because $\mathbf{P}_m$ is a token prior function. Hence
    \[
    \mathbf{P}^{br}_m(T(x))=\mathbf{P}^{br}_m(\epsilon)=1=x.\mathbf{P},
    \]
    so the stored value is correct.

    Now suppose $x\neq \epsilon$.
    By the precondition, the token ancestor $\pi(x)$ already has time $m$,
    so its stored value is correct:
    \[
    \pi(x).\mathbf{P}=\mathbf{P}^{br}_m(T(\pi(x))).
    \]
    By lemma~\ref{lemma:token-prefix-retokenization},
    \[
    T(\pi(x)) = T(x)[:-1].
    \]
    Thus,
    \[
    \pi(x).\mathbf{P}=\mathbf{P}^{br}_m(T(x)[:-1]).
    \]
    The algorithm then sets
    \[
    x.\mathbf{P}
    \gets
    \pi(x).\mathbf{P}\cdot \mathbf{Q}_m(T(x)[-1]\mid T(x)[:-1]).
    \]
    Substituting the known ancestor value gives
    \[
    x.\mathbf{P}
    =
    \mathbf{P}^{br}_m(T(x)[:-1])\cdot \mathbf{Q}_m(T(x)[-1]\mid T(x)[:-1]).
    \]
    By lemma~\ref{lemma:token-branch-prior-product},
    \[
    \mathbf{P}^{br}_m(T(x))
    =
    \mathbf{P}^{br}_m(T(x)[:-1])\cdot \mathbf{Q}_m(T(x)[-1]\mid T(x)[:-1]).
    \]
    Therefore $x.\mathbf{P}=\mathbf{P}^{br}_m(T(x))$, as required.

    Finally, the assignment $x.m_\mathbf{P}\gets m$ records exactly the time at
    which this value is valid.
\end{proof}

\begin{theorem}[Compute Branch Prior Correctness]
    Algorithm~\ref{alg:compute-branch-prior} correctly computes the branch prior of a node.
\end{theorem}
\begin{proof}
    We must show that after the algorithm runs,
    \[
    x.P = P^{br}_m(x).
    \]
    By the precondition, every strict string ancestor $x[:i]$ has already had its
    token branch prior computed at time $m$. Thus for every $i < |x|$,
    \[
    (x[:i]).\mathbf{P}=\mathbf{P}^{br}_m(T(x[:i])).
    \]

    By theorem~\ref{theorem:string-ancestor-reindexing},
    \[
    P^{br}_m(x)
    =
    \sum_{i=0}^{|x|-1}
    \mathbf{P}^{br}_m(\kappa_x(i)) \, \Phi_m(\kappa_x(i),x).
    \]
    Using definition~\ref{def:string-prefix-context}, this becomes
    \[
    P^{br}_m(x)
    =
    \sum_{i=0}^{|x|-1}
    \mathbf{P}^{br}_m(T(x[:i])) \, \Phi_m(T(x[:i]),x).
    \]
    Replacing each $\mathbf{P}^{br}_m(T(x[:i]))$ by the already-computed stored
    value $(x[:i]).\mathbf{P}$ gives
    \[
    P^{br}_m(x)
    =
    \sum_{i=0}^{|x|-1}
    (x[:i]).\mathbf{P}\,\Phi_m(\kappa_x(i),x).
    \]
    This is exactly the value assigned to $x.P$ by the algorithm.
    Therefore the algorithm correctly computes the branch prior of $x$.

    Finally, the assignment $x.m_P\gets m$ records the time at which this branch
    prior value is valid.
\end{proof}


Two implementation remarks are useful in practice:
\begin{enumerate}
    \item The relevant contexts for a literal prefix $x$ are governed only by token
    boundaries that can occur within the final token overlapping $x$.
    When tokens cannot contain spaces internally, this means that only prefixes of the
    final word need be considered.
    For a tokenizer with maximum token length $L$, this limits the search to at most the
    last $L$ characters.
    \item If the vocabulary is stored in lexicographic order and the model output is
    converted to cumulative probabilities, then the fan
    $\Phi_M(\mathbf{b},x)$ can be obtained from a difference of cumulative sums over the
    contiguous lexicographic range of tokens $\boldsymbol{\tau}$ satisfying
    $x\le T^{-1}(\mathbf{b}+\boldsymbol{\tau})$. (Given how we defined our comparison conventions it is permissible to write this as, $\boldsymbol{\tau} \leq \mathbf{b} - x$.)
\end{enumerate}

\section{Maximum Truncation Compatible Descendant Likelihood}
\label{sec:maximum-descendant-likelihood}
We now discuss how to track the maximum truncation compatible descendant likelihood for nodes.
The quantity is not needed to compute posteriors and is orthogonal to the 
preceding discussion. However, it will be helpful later for determining
which token sequences should be evaluated by the language model.

The algorithm somewhat resembles the core posterior calculation algorithm, in that we
begin by updating the computation on a frontier and then update it within the frontier with
a kind of up-propagation algorithm.

We begin by defining truncating a string to a token sequence.
\begin{definition}[Token Truncation]
    The token truncation of a string $x$ under a token sequence $\mathbf{a}$ is the longest prefix
    of $\mathbf{a}$ that is also, as a string, a prefix of $x$. It maps a string to a token sequence,
    and is written as $\lfloor x \rfloor_{\mathbf{a}}$. (Context makes it clear when 
    this is intended as opposed to complete prefix code truncation, which uses the same notation,
    but with a complete prefix code instead of a token sequence in the subscript.)
    $$
    \btrunc{x}{\mathbf{a}} = \max_{\substack{\mathbf{b} \leq \mathbf{a} \\ \mathbf{b} \leq x}} \mathbf{b}
    $$
\end{definition}

\begin{lemma}[Token truncation is transitive along string prefixes]
    \label{lemma:token-truncation-string-prefix-transitivity}
    If $x \leq f$, then for every token sequence $\mathbf{c}$,
    $$
    \btrunc{x}{\btrunc{f}{\mathbf{c}}} = \btrunc{x}{\mathbf{c}}.
    $$
\end{lemma}
\begin{proof}
    By definition,
    $$
    \btrunc{x}{\btrunc{f}{\mathbf{c}}}
    =
    \max_{\substack{
        \mathbf{b} \leq \btrunc{f}{\mathbf{c}} \\
        \mathbf{b} \leq x
    }}
    \mathbf{b}.
    $$
    Since
    $$
    \btrunc{f}{\mathbf{c}}
    =
    \max_{\substack{
        \mathbf{d} \leq \mathbf{c} \\
        \mathbf{d} \leq f
    }}
    \mathbf{d},
    $$
    a token sequence $\mathbf{b}$ satisfies $\mathbf{b} \leq \btrunc{f}{\mathbf{c}}$ if and only if
    $\mathbf{b} \leq \mathbf{c}$ and $\mathbf{b} \leq f$.

    Therefore the indexing set above is exactly
    $$
    \left\{
        \mathbf{b} \;\middle|\; \mathbf{b} \leq \mathbf{c},\ \mathbf{b} \leq f,\ \mathbf{b} \leq x
    \right\}.
    $$
    Because $x \leq f$, every token sequence whose string is a prefix of $x$ is automatically a prefix of $f$.
    Hence this set is equal to
    $$
    \left\{
        \mathbf{b} \;\middle|\; \mathbf{b} \leq \mathbf{c},\ \mathbf{b} \leq x
    \right\}.
    $$
    Taking the maximum over this set gives
    $$
    \btrunc{x}{\btrunc{f}{\mathbf{c}}}
    =
    \max_{\substack{
        \mathbf{b} \leq \mathbf{c} \\
        \mathbf{b} \leq x
    }}
    \mathbf{b}
    =
    \btrunc{x}{\mathbf{c}},
    $$
    as claimed.
\end{proof}

\begin{definition}[Maximum Truncation Compatible Descendant Likelihood]
\label{def:maximum-truncation-compatible-descendant-likelihood}
    The maximum truncation compatible descendant likelihood is the maximum likelihood of any descendant, $h$, 
    for which the canonical tokenization is an extension of $\mathbf{a}$ and makes $\mathbf{a}$ the
    token truncation of $x$. If there is no such descendant, this maximum is taken to be $0$.
    $$
    R_n(\mathbf{a}, x) =
    \max_{\substack{
        h \in H \\
        x \leq h \\
        \mathbf{a} \leq T(h) \\
        \btrunc{x}{T(h)} = \mathbf{a}
    }}
    L_n(h)
    $$
\end{definition}

In the special case where the string corresponds to the token sequence, this reduces to,
\begin{lemma}[Identical Token and String Prefixes]
    If $\mathbf{a} = T(a)$, then
    $$
    R_n(\mathbf{a}, a) = \max_{\substack{h \in H \\ \mathbf{a} \leq T(h)}} L_n(h)
    $$
\end{lemma}
\begin{proof}
    If $\mathbf{a}$ is properly terminated then $h = a$ satisfies the conditions.
    Otherwise, if $\mathbf{a}$ is not terminated, then $h = a + \boldsymbol{\omega}$ satisfies the conditions,
    since the stop character is always required to tokenize as its own token.
\end{proof}
This latter quantity, the maximum likelihood of any descendant of a token sequence, is the quantity of interest,
but we will need a datastructure that maintains $R_n(\mathbf{a}, x)$ for other values of $x$, $x > \mathbf{a}$.

    \begin{lemma}[Frontier ancestors of a descendant extending a covered prefix]
    \label{lemma:frontier-ancestor-extending-covered-prefix}
        Let $F$ be a prefix code, let $x$ be a string satisfying $x \leq F$, and let $h$ be a string
        satisfying $x \leq h$. If $f \in F$ and $f \leq h$, then $x \leq f$.
    \end{lemma}
    \begin{proof}
        Because $x \leq F$, there exists some $g \in F$ such that $x \leq g$.
        Since both $f$ and $x$ are prefixes of $h$, they are comparable. If $f < x$, then
        $f < x \leq g$, so $f$ and $g$ are comparable distinct elements of the prefix code $F$,
        a contradiction. Hence $f \not< x$, and therefore $x \leq f$.
    \end{proof}

The core theorem required for our algorithm relates the truncation compatible descendant likelihood to the same quantity on
an arbitrary frontier.

\begin{theorem}[Truncation Compatible Descendant Likelihood from the Frontier]
\label{theorem:truncation-compatible-descendant-likelihood-from-frontier}
Given a canonical token sequence $\mathbf{a}$, a string $x$, a complete prefix code $F \leq H$,
and a likelihood time $n$,
such that $x \leq F$,
$$
R_n(\mathbf{a}, x) =
    \max_{\substack{
        f \in F \\
        x \leq f
    }}
    \;\;
    \max_{\substack{
        \mathbf{b} \in \mathbf{C} \\
        \mathbf{a} \leq \mathbf{b} \leq f \\
        \btrunc{x}{\mathbf{b}} = \mathbf{a}
    }} 
    R_n(\mathbf{b}, f),
$$
\end{theorem}
\begin{proof}
    We prove both inequalities.

    First, let $h \in H$ be any string satisfying
    $$
    x \leq h, \quad \mathbf{a} \leq T(h), \quad \btrunc{x}{T(h)} = \mathbf{a}.
    $$
    Because $F \leq H$ and $h \in H$, there exists $f \in F$ such that $f \leq h$.
    By lemma~\ref{lemma:frontier-ancestor-extending-covered-prefix}, $x \leq f$, so
    $x \leq f \leq h$.

    Let
    $$
    \mathbf{b} := \btrunc{f}{T(h)}.
    $$
    Then $\mathbf{b} \leq T(h)$, so proposition~\ref{prop:tokenization-prefixes-are-canonical}
    gives $\mathbf{b} \in \mathbf{C}$. Also $\mathbf{b} \leq f$ and $\mathbf{a} \leq \mathbf{b}$.
    Moreover, by lemma~\ref{lemma:token-truncation-string-prefix-transitivity},
    $$
    \btrunc{x}{\mathbf{b}}
    =
    \btrunc{x}{\btrunc{f}{T(h)}}
    =
    \btrunc{x}{T(h)}
    =
    \mathbf{a}.
    $$
    Since $f \leq h$, $\mathbf{b} \leq T(h)$, and $\btrunc{f}{T(h)} = \mathbf{b}$,
    the string $h$ is admissible in the definition of $R_n(\mathbf{b}, f)$.
    Hence
    $$
    L_n(h) \leq R_n(\mathbf{b}, f).
    $$
    Because every admissible $h$ for $R_n(\mathbf{a}, x)$ yields such a pair $(\mathbf{b}, f)$,
    this proves
    $$
    R_n(\mathbf{a}, x)
    \leq
    \max_{\substack{
        f \in F \\
        x \leq f
    }}
    \;\;
    \max_{\substack{
        \mathbf{b} \in \mathbf{C} \\
        \mathbf{a} \leq \mathbf{b} \leq f \\
        \btrunc{x}{\mathbf{b}} = \mathbf{a}
    }}
    R_n(\mathbf{b}, f).
    $$

    For the reverse inequality, let $\mathbf{b} \in \mathbf{C}$ and $f \in F$ satisfy
    $$
    x \leq f, \quad \mathbf{a} \leq \mathbf{b} \leq f, \quad \btrunc{x}{\mathbf{b}} = \mathbf{a}.
    $$
    If there is no $h \in H$ admissible in the definition of $R_n(\mathbf{b}, f)$, then
    $R_n(\mathbf{b}, f) = 0 \leq R_n(\mathbf{a}, x)$ by definition.
    Otherwise, let $h \in H$ satisfy
    $$
    f \leq h, \quad \mathbf{b} \leq T(h), \quad \btrunc{f}{T(h)} = \mathbf{b}.
    $$
    Since $x \leq f \leq h$, we have $x \leq h$. Also, again by
    lemma~\ref{lemma:token-truncation-string-prefix-transitivity},
    $$
    \btrunc{x}{T(h)}
    =
    \btrunc{x}{\btrunc{f}{T(h)}}
    =
    \btrunc{x}{\mathbf{b}}
    =
    \mathbf{a}.
    $$
    Because $\mathbf{a} \leq \mathbf{b} \leq T(h)$, the string $h$ is admissible in the
    definition of $R_n(\mathbf{a}, x)$. Hence every value contributing to $R_n(\mathbf{b}, f)$
    also contributes to $R_n(\mathbf{a}, x)$, so
    $$
    R_n(\mathbf{b}, f) \leq R_n(\mathbf{a}, x).
    $$
    Taking the maximum over all such $\mathbf{b}$ and $f$ gives
    $$
    \max_{\substack{
        f \in F \\
        x \leq f
    }}
    \;\;
    \max_{\substack{
        \mathbf{b} \in \mathbf{C} \\
        \mathbf{a} \leq \mathbf{b} \leq f \\
        \btrunc{x}{\mathbf{b}} = \mathbf{a}
    }}
    R_n(\mathbf{b}, f)
    \leq
    R_n(\mathbf{a}, x).
    $$

    Therefore the two sides are equal.
\end{proof}

\begin{lemma}[Canonical token prefixes of a string]
    \label{lemma:canonical-token-prefixes-of-a-string}
    Let $f$ be a string. The canonical token sequences $\mathbf{b}$ satisfying $\mathbf{b} \leq f$
    are exactly those of the form
    $$
    \mathbf{b} = T(f[:i])
    $$
    for some $i \leq |f|$.
\end{lemma}
\begin{proof}
    First suppose $\mathbf{b} \leq f$ and $\mathbf{b}$ is canonical. Then there exists a string
    $b = T^{-1}(\mathbf{b})$ with $b \leq f$. Writing $i := |b|$, we have $b = f[:i]$, and therefore
    $$
    \mathbf{b}
    =
    T(b)
    =
    T(f[:i]).
    $$

    Conversely, let $i \leq |f|$. Then $f[:i] \leq f$, so
    $$
    T^{-1}(T(f[:i])) = f[:i] \leq f.
    $$
    Thus $T(f[:i])$ is canonical and satisfies $T(f[:i]) \leq f$.
\end{proof}

\begin{corollary}[Truncation Compatible Descendant Likelihood from the Frontier, Reindexed]
    Given a canonical token sequence $\mathbf{a}$, a string $x$, a complete prefix code $F$,
    and a likelihood time $n$,
    such that $x \leq F$ and $H \geq F$,
    $$
    R_n(\mathbf{a}, x)
    =
    \max_{\substack{
        f \in F \\
        x \leq f
    }}
    \;\;
    \max_{\substack{
        i \leq |f| \\
        \btrunc{x}{T(f[:i])} = \mathbf{a}
    }}
    R_n(T(f[:i]), f).
    $$
\end{corollary}
\begin{proof}
    By theorem~\ref{theorem:truncation-compatible-descendant-likelihood-from-frontier},
    $$
    R_n(\mathbf{a}, x) =
    \max_{\substack{
        f \in F \\
        x \leq f
    }}
    \;\;
    \max_{\substack{
        \mathbf{b} \in \mathbf{C} \\
        \mathbf{a} \leq \mathbf{b} \leq f \\
        \btrunc{x}{\mathbf{b}} = \mathbf{a}
    }}
    R_n(\mathbf{b}, f).
    $$
    For fixed $f \in F$, lemma~\ref{lemma:canonical-token-prefixes-of-a-string}
    shows that the canonical token sequences $\mathbf{b}$ satisfying $\mathbf{b} \leq f$
    are exactly those of the form $\mathbf{b} = T(f[:i])$ for $i \leq |f|$.
    Reindexing the outer maximum by this correspondence yields the claim.
\end{proof}
This prepares us for our first, algorithm,

We compute a quanitity, $\widehat{R}(\mathbf{a}, x)$.
In implementation, this is data attached to the node, $x$,
indexed by its ancestors, $\mathbf{a}$.
Our goal is to design an algorithm that correctly computes $\widehat{R}(\mathbf{a}, x)$
at time $N_R$,
i.e., $\widehat{R}(\mathbf{a}, x) = R_{N_R}(\mathbf{a}, x)$.

\begin{algorithm}[H]
\caption{MTCDL Up Propagation}
\label{alg:mtcdl-up-propagation}
\begin{algorithmic}[1]
\Require Complete Prefix Code, $F$
\Require $H \geq F$
\Require New max likelihood tracking time, $N_R$
\Require $x.n_R = N_R$
\Comment{All frontier nodes already have the new max likelihood tracking time}
\Require $f \in F \implies \widehat{R}(\mathbf{d}, f) = R_{N_R}(\mathbf{d}, f)$ for all canonical $\mathbf{d} \leq f$.
\Comment{MTCDLFA Already Correct at Frontier}
\Require $x < F \implies \widehat{R}(\mathbf{d}, x) \leq R_{N_R}(\mathbf{d}, x)$ for all canonical $\mathbf{d} \leq x$.
\For{each node $f \in F$}
    \For{$i \leq |f|$}
        \State $\mathbf{b} \gets T(f[:i])$
        \Comment{Canonical tokenizations of each string ancestor of $f$}
        \For{$j$ from $|f|$ down to $0$}
            \State $\widehat{R}(\btrunc{f[:j]}{\mathbf{b}}, f[:j]) \gets_{\max} \widehat{R}(\mathbf{b}, f)$
        \EndFor
    \EndFor
\EndFor
\For{each node $x < F$}
\Comment{Update the local max likelihood tracking time of all nodes}
    \State $x.n_R \gets N_R$
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{theorem}[MTCDL Up Propagation Correctness]
\label{theorem:mtcdl-up-propagation-correctness}
Under the hypotheses of algorithm~\ref{alg:mtcdl-up-propagation},
if $H \geq F$, $\mathbf{a} \leq F$, and $x \leq F$, then
\[
R_{N_R}(\mathbf{a}, x) = \widehat{R}(\mathbf{a}, x).
\]
\end{theorem}
\begin{proof}
    Fix $\mathbf{a} \leq F$ and $x \leq F$.
    By inspection of algorithm~\ref{alg:mtcdl-up-propagation},
    the value $\widehat{R}(\mathbf{a}, x)$ at termination is the maximum of its initial value
    and all values $\widehat{R}(T(f[:i]), f)$ such that $f \in F$, $x \leq f$, and
    $\btrunc{x}{T(f[:i])} = \mathbf{a}$.
    Thus
    $$
    \widehat{R}(\mathbf{a}, x)
    =
    \max \Bigg(
        \widehat{R}^{\mathrm{init}}(\mathbf{a}, x),
        \;\;
        \max_{\substack{
            f \in F \\
            x \leq f
        }}
        \;
        \max_{\substack{
            i \leq |f| \\
            \btrunc{x}{T(f[:i])} = \mathbf{a}
        }}
        \widehat{R}(T(f[:i]), f)
    \Bigg).
    $$
    By the initialization hypothesis, $\widehat{R}^{\mathrm{init}}(\mathbf{a}, x) \leq R_{N_R}(\mathbf{a}, x)$.
    Also, for every $f \in F$ and $i \leq |f|$, the frontier hypothesis gives
    $$
    \widehat{R}(T(f[:i]), f) = R_{N_R}(T(f[:i]), f).
    $$
    Therefore
    $$
    \widehat{R}(\mathbf{a}, x)
    =
    \max \Bigg(
        \widehat{R}^{\mathrm{init}}(\mathbf{a}, x),
        \;\;
        \max_{\substack{
            f \in F \\
            x \leq f
        }}
        \;
        \max_{\substack{
            i \leq |f| \\
            \btrunc{x}{T(f[:i])} = \mathbf{a}
        }}
        R_{N_R}(T(f[:i]), f)
    \Bigg).
    $$
    By the reindexed corollary above,
    the second term is exactly $R_{N_R}(\mathbf{a}, x)$. Hence the maximum above is
    $\max(\widehat{R}_{\mathrm{init}}(\mathbf{a}, x), R_{N_R}(\mathbf{a}, x)) = R_{N_R}(\mathbf{a}, x)$.
\end{proof}


The preceding algorithm explains how to update within the frontier
to a new likelihood time. We now give a simple update algorithm
for beyond the frontier.

\begin{algorithm}[H]
\caption{MTCDL Update}
\label{alg:mtcdl-update}
\begin{algorithmic}[1]
\Require Node $x$
\Require New max likelihood tracking time $n'_R$
\Require $n'_R \geq x.n_R$
\Comment{The new likelihood time is not earlier than the node's local time}
\Require $\widehat{R}(\mathbf{d}, x) = R_{x.n_R}(\mathbf{d}, x)$ for all canonical $\mathbf{d} \leq x$.
\Require $x \geq \bigvee_{i=x.n_R+1}^{n'_R} C^L_i$
\State $\widehat{R}(\mathbf{d}, x) \mathrel{*=} \prod_{i=x.n_R+1}^{n'_R} \Delta^L_i(\lfloor x \rfloor_{C^L_i}) \quad \text{for all canonical } \mathbf{d} \leq x$
\State $x.n_R \gets n'_R$
\end{algorithmic}
\end{algorithm}

\begin{lemma}[MTCDL Likelihood Factorization]
\label{lemma:mtcdl-likelihood-factorization}
    Let $n \leq n'$ and let $x$ be a string satisfying
    \[
    x \geq \bigvee_{i=n+1}^{n'} C^L_i.
    \]
    Then for every canonical token sequence $\mathbf{a} \leq x$,
    \[
    R_{n'}(\mathbf{a}, x)
    =
    R_n(\mathbf{a}, x)
    \prod_{i=n+1}^{n'} \Delta^L_i(\lfloor x \rfloor_{C^L_i}).
    \]
\end{lemma}
\begin{proof}
    By the definition of a likelihood delta digest sequence, for every $h \in H$,
    \[
    L_{n'}(h)
    =
    L_n(h)\prod_{i=n+1}^{n'} \Delta^L_i(\lfloor h \rfloor_{C^L_i}).
    \]
    Since $x \geq \bigvee_{i=n+1}^{n'} C^L_i$, the same argument as in
    lemma~\ref{lemma:eventually-constant-likelihoods} shows that for every
    $h \geq x$ and every $i \in \{n+1,\dots,n'\}$,
    \[
    \lfloor h \rfloor_{C^L_i} = \lfloor x \rfloor_{C^L_i}.
    \]
    Hence, for all $h \geq x$,
    \[
    L_{n'}(h)
    =
    L_n(h)\prod_{i=n+1}^{n'} \Delta^L_i(\lfloor x \rfloor_{C^L_i}).
    \]

    If there is no $h \in H$ admissible in the definition of $R_n(\mathbf{a}, x)$,
    then both $R_n(\mathbf{a}, x)$ and $R_{n'}(\mathbf{a}, x)$ are $0$ by
    definition, and the claim follows. Otherwise,
    \begin{align*}
    R_{n'}(\mathbf{a}, x)
    &=
    \max_{\substack{
        h \in H \\
        x \leq h \\
        \mathbf{a} \leq T(h) \\
        \btrunc{x}{T(h)} = \mathbf{a}
    }}
    L_{n'}(h) \\
    &=
    \max_{\substack{
        h \in H \\
        x \leq h \\
        \mathbf{a} \leq T(h) \\
        \btrunc{x}{T(h)} = \mathbf{a}
    }}
    \left(
        L_n(h)\prod_{i=n+1}^{n'} \Delta^L_i(\lfloor x \rfloor_{C^L_i})
    \right) \\
    &=
    \left(
        \max_{\substack{
            h \in H \\
            x \leq h \\
            \mathbf{a} \leq T(h) \\
            \btrunc{x}{T(h)} = \mathbf{a}
        }}
        L_n(h)
    \right)
    \prod_{i=n+1}^{n'} \Delta^L_i(\lfloor x \rfloor_{C^L_i}) \\
    &=
    R_n(\mathbf{a}, x)
    \prod_{i=n+1}^{n'} \Delta^L_i(\lfloor x \rfloor_{C^L_i}),
    \end{align*}
    as claimed.
\end{proof}

\begin{theorem}[MTCDL Update Correctness]
    Under the hypotheses of algorithm~\ref{alg:mtcdl-update},
    after execution,
    \[
    \widehat{R}(\mathbf{a}, x) = R_{n'}(\mathbf{a}, x)
    \]
    for all canonical $\mathbf{a} \leq x$.
\end{theorem}
\begin{proof}
    Let $n := x.n_R$ before execution of the algorithm, and fix a canonical
    token sequence $\mathbf{a} \leq x$.
    By the precondition,
    \[
    \widehat{R}(\mathbf{a}, x) = R_n(\mathbf{a}, x).
    \]
    By lemma~\ref{lemma:mtcdl-likelihood-factorization},
    \[
    R_{n'}(\mathbf{a}, x)
    =
    R_n(\mathbf{a}, x)
    \prod_{i=n+1}^{n'} \Delta^L_i(\lfloor x \rfloor_{C^L_i}).
    \]
    The algorithm multiplies $\widehat{R}(\mathbf{a}, x)$ by this same factor, so the
    updated value satisfies
    \begin{align*}
    \widehat{R}(\mathbf{a}, x)
    &=
    R_n(\mathbf{a}, x)
    \prod_{i=n+1}^{n'} \Delta^L_i(\lfloor x \rfloor_{C^L_i}) \\
    &=
    R_{n'}(\mathbf{a}, x).
    \end{align*}
    Since $\mathbf{a}$ was arbitrary, the conclusion holds for all canonical
    $\mathbf{a} \leq x$.
\end{proof}

We now discuss machinery to initialize the maximum truncation compatible descendant likelihood for nodes at time
$N_R=0$. 
For this, we need the further assumption that our
tokenizer has the property of canonical concatenation.

\begin{definition}[Canonical Concatenation]
    A tokenizer has the property of canonical concatenation
    if overlapping canonical token sequences---with the overlap nonempty---can be concatenated to form a longer canonical token sequence.
    I.e.,
    $$
    \begin{aligned}
        &\text{For all } \mathbf{a}, \mathbf{b}, \mathbf{c} \in \mathbf{C}, \;\; \mathbf{b} \neq \mathbf{\epsilon}, \\
        &\quad \Big( \mathbf{a} + \mathbf{b} \in \mathbf{C} \;\land\; \mathbf{b} + \mathbf{c} \in \mathbf{C} \Big)
        \;\implies\; \mathbf{a} + \mathbf{b} + \mathbf{c} \in \mathbf{C}
    \end{aligned}
    $$
\end{definition}

In the appendix section~\ref{sec:appendix-bpe-mechanics},
we show that any BPE tokenizer has the property of canonical concatenation.

\begin{definition}[Possible Truncation Predicate]
    The predicate, $\phi(\mathbf{a}, x)$, indicates whether there exists a descendant $h$ of $x$
    whose tokenization truncates $x$ to $\mathbf{a}$.
    $$
    \phi(\mathbf{a}, x)
    \iff
    \exists h \;\bigl( x \leq h \land \btrunc{x}{T(h)} = \mathbf{a} \bigr)
    $$
\end{definition}

\begin{definition}[Canonical Token Pair Predicate]
    The canonical token pair predicate, $\psi(\boldsymbol{\tau_1}, \boldsymbol{\tau_2})$, indicates whether a pair of tokens are canonical.
    $$
    \psi(\boldsymbol{\tau_1}, \boldsymbol{\tau_2})
    \iff
    T(\rho(\boldsymbol{\tau_1}) + \rho(\boldsymbol{\tau_2})) = [\boldsymbol{\tau_1}, \boldsymbol{\tau_2}]
    $$
\end{definition}

\begin{definition}[String Vocabulary]
    The set of strings corresponding to the vocabulary
    is the ``string vocabulary'', denoted $V$.
\end{definition}

\begin{definition}[Vocabulary Prefix Set]
    The vocabulary prefix set, $V_{\leq}$,
    is the set of all strings that are prefixes of some string in the vocabulary, $V$.
\end{definition}

\begin{definition}[Canonical Token Prefix Pair Predicate]
    We define the canonical token prefix pair predicate, $\xi$ to indicate whether a given prefix could canonically follow a given token.
    $$
    \xi : \boldsymbol{\Lambda} \times V_\leq \to \mathbb{B}
    $$
    with
    $$
    \xi(\boldsymbol{\tau_1}, v) \iff \exists \boldsymbol{\tau_2} \in \boldsymbol{\Lambda}, \psi(\boldsymbol{\tau_1}, \boldsymbol{\tau_2}) \land v \leq \boldsymbol{\tau_2}
    $$
\end{definition}

\begin{corollary}[BPE Last-Token Extension]
    \label{cor:bpe-last-token-extension-local}
    Assume the tokenization function is induced by a BPE merge system as in
    section~\ref{sec:appendix-bpe-mechanics}. Let $\mathbf{a} \in \mathbf{C}$ be nonempty,
    and let $\boldsymbol{\tau}$ be a token. If
    \[
    \psi(\mathbf{a}[-1], \boldsymbol{\tau}),
    \]
    then
    \[
    \mathbf{a}+\boldsymbol{\tau} \in \mathbf{C}.
    \]
\end{corollary}
\begin{proof}
    This is exactly corollary~\ref{cor:bpe-last-pair-extension}.
\end{proof}
\begin{theorem}[Possible Truncation Predicate from Canonical Token Prefix Pair Predicate]
    We may calculate the possible truncation predicate, $\phi$, from the canonical token prefix pair predicate, $\xi$.
    $$
    \phi(\mathbf{a}, x)
    \iff
    \left( \mathbf{a} = \mathbf{\epsilon} \land x \in V_{\leq} \right)
    \lor
    \xi(\mathbf{a}[-1], x - \mathbf{a})
    $$
\end{theorem}
\begin{proof}
    We prove both directions.
    
    If $\phi(\mathbf{a}, x)$ is true, then there exists a descendant $h$ of $x$
    whose tokenization truncates $x$ to $\mathbf{a}$.
    If $\mathbf{a} = \mathbf{\epsilon}$, then $x \leq \rho(T(h)[0])$, so $x \in V_{\leq}$ and we are done.
    Otherwise, let $\boldsymbol{\tau} = \mathbf{a}[-1]$, and
    $\boldsymbol{\tau_2} = T(h)[|\mathbf{a}|]$, the next token in $T(h)$ after the last token of $\mathbf{a}$.
    We have $x - \mathbf{a} \leq \boldsymbol{\tau_2}$ and by the boundary sufficiency of $T(h)$ we have $\psi(\boldsymbol{\tau}, \boldsymbol{\tau_2})$,
    hence $\xi(\boldsymbol{\tau}, x - \mathbf{a})$ holds.

    Conversely, if $\xi(\boldsymbol{\tau}, x - \mathbf{a})$ is true, then there exists a token $\boldsymbol{\tau_2}$ such that $\psi(\boldsymbol{\tau}, \boldsymbol{\tau_2}) \land (x - \mathbf{a} \leq \boldsymbol{\tau_2})$.
    We may then construct $h = T^{-1}(\mathbf{a} + \boldsymbol{\tau_2} + \boldsymbol{\omega})$
    which by corollary~\ref{cor:bpe-last-token-extension-local} has $T(h) = \mathbf{a} + \boldsymbol{\tau_2} + \boldsymbol{\omega}$,
    guaranteeing that $x \leq h$ and $\btrunc{x}{T(h)} = \mathbf{a}$.

\end{proof}

\begin{theorem}[Maximum Truncation Compatible Descendant Likelihood from Possible Truncation Predicate]
    Recall that $\forall h,\ L_0(h) = 1$. Then
    \[
    R_0(\mathbf{a}, x) =
    \begin{cases}
        1 & \text{if } \phi(\mathbf{a}, x), \\[3ex]
        0 & \text{otherwise.}
    \end{cases}
    \]
\end{theorem}
\begin{proof}
\end{proof}

\subsubsection{Efficient Evaluation of the Possible Truncation Predicate}
Corollary~\ref{cor:bpe-last-token-extension-local} shows that, in the BPE setting,
the question of whether a candidate next token preserves canonicality depends only on the
last token of the current canonical token sequence. This motivates the predicate $\xi$.

I do not currently have a complete exact characterization of the possible truncation predicate,
$\phi$, solely in terms of $\xi$ and a vocabulary-prefix lookup.

Computing the predicate $\in V_\leq$ is straightforward.
One solution would be to maintain a trie of the string vocabulary, $V$.

The former predicate, $\xi$, is much more difficult, 
and has resisted my attempts to find an efficient algorithm.
However, it can be solved in $O(1)$ time by precomputing a lookup table for all possible pairs in
$\boldsymbol{\Lambda} \times V_\leq$.
Using reasonable values of $|\boldsymbol{\Lambda}|=50,000$
and $|V_\leq|=100,000$, this table has 5,000,000,000 entries.
Assuming 1 bit of memory per entry, this is about 600MB.

I studied the problem of compressing the closely related
lookup table for the canonical token pair predicate, $\psi$.
I found that for a random choice of $\boldsymbol{\sigma}$ and $\boldsymbol{\tau}$, the probability that $\boldsymbol{\sigma} + \boldsymbol{\tau}$ tokenizes to $[\boldsymbol{\sigma}, \boldsymbol{\tau}]$ is about $1/2$.
Knowing either argument does not help very much: the conditional entropy is still about $0.6$ bits in either case.

However, since this predicate is only required on the server and not in the browser, we can afford a 600MB lookup table,
since the language model will be several gigabytes anyway.

\section{The Complete Algorithms}
\label{sec:complete-algorithms}
Here we combine the preceding sections
to give Dotter's complete algorithms.
The tracking of the maximum descendant likelihood
is optional and will only run on the server.
We denote the trie's global maximum descendant likelihood tracking time by $B.N_R$,
corresponding to the local times $x.n_R$.


\begin{algorithm}[H]
\caption{Complete Prior Update}
\begin{algorithmic}[1]
\Require Bayesian Trie $B$.
\State $N'_Z \gets B.N_Z$
\State $M'_Z \gets B.M_Z + 1$
\State $M'_P \gets B.M_P + 1$
\State $M'_\mathbf{P} \gets B.M_\mathbf{P} + 1$
\Comment{In the present algorithms, $M'_Z$, $M'_P$, and $M'_\mathbf{P}$ remain synchronized.}
\State $F \gets \emptyset$
\For{each node $x$ in the trie in topological order}

    \Comment{Run algorithm~\ref{alg:compute-token-branch-prior}, Compute Token Branch Prior, on $x$ with new time $M'_\mathbf{P}$.}
    \If{$x = \epsilon$}
        \State $x.\mathbf{P} \gets 1$
    \Else
        \State $x.\mathbf{P} \gets \pi(x).\mathbf{P} * \mathbf{Q}_{M'_\mathbf{P}}(T(x)[-1] \mid T(x)[:-1])$
    \EndIf
    \State $x.m_\mathbf{P} \gets M'_\mathbf{P}$

    \Comment{Run algorithm~\ref{alg:push-likelihood}, Push Likelihood, on $x$.}
    \State $y.l \gets y.l * x.l \quad \forall y \in x.\text{children}$
    \State $x.l \gets 1$
    \State $x.n_t \gets B.N_t$

    \Comment{Locate the update frontier, $F$.}
    \If{$x \geq \bigvee_{i=1}^{N'_Z} C^L_i$ or $x \geq C^P_{M'_Z}$}
        \State $F \gets F \cup \{x\}$
        \State \text{Break descent from $x$}
    \EndIf
\EndFor
\For{each node $x \in F$}

    \Comment{Run algorithm~\ref{alg:compute-branch-prior}, Compute Branch Prior, on $x$ with new time $M'_P$.}
    \State $x.P \gets \sum_{i=0}^{|x|-1} (x[:i]).\mathbf{P} * \Phi_{M'_P}(\kappa_x(i), x)$
    \State $x.m_P \gets M'_P$

    \Comment{Run the first half of algorithm~\ref{alg:advance-trie-time}, Advance Trie Time, on $B$ to $(N'_Z, M'_Z)$.}

    \Comment{Run algorithm~\ref{alg:advance-node-time-recalculation}, Advance Node Time, on $x$ to $(N'_Z, M'_Z)$.}
    \State $x.Z \gets x.Z * (x.P / x.P^{old}) * x.l$ 
    \State $x.P^{old} \gets x.P$
    \State $x.n_Z \gets N'_Z$
    \State $x.m_Z \gets M'_Z$
\EndFor

\Comment{Run the second half of algorithm~\ref{alg:advance-trie-time}, Advance Trie Time, on $B$ to $(N'_Z, M'_Z)$.}
\For{each node $x < F$ in reverse topological order}
    \State $x.Z \gets \sum_{y \in x.\text{children}} y.\text{Z}$
    \State $x.n_Z \gets N'_Z$
    \State $x.m_Z \gets M'_Z$
\EndFor
\State $B.M_Z \gets M'_Z$
\State $B.M_P \gets M'_P$
\State $B.M_\mathbf{P} \gets M'_\mathbf{P}$
\end{algorithmic}
\end{algorithm}


\begin{algorithm}[H]
\caption{Complete Likelihood Update}
\label{alg:complete-likelihood-update}
\begin{algorithmic}[1]
\Require Bayesian Trie $B$.
\State $N'_t \gets B.N_t + 1$
\State $N'_Z \gets B.N_Z + 1$
\State $N'_R \gets B.N_R + 1$

    \State $x.l \gets 1$
    \State $x.n_t \gets B.N_t$
\EndFor

\section{Appendix: Byte-Pair Encoding Mechanics}
\label{sec:appendix-bpe-mechanics}

We now specialize the general tokenization formalism of this chapter to byte-pair encoders.
Our goal is to prove a structural property that is stronger than boundary sufficiency and is
specific to BPE tokenizers.

Throughout this appendix we identify each BPE token with its spelling.
Thus a token is itself a nonempty string over the character alphabet $\Lambda$,
and the literalization map is just concatenation of tokens.

\begin{definition}[Character Tokenization]
    For a string $x = x_1 \cdots x_n$, let
    \[
    \operatorname{chars}(x) = [x_1, \ldots, x_n]
    \]
    denote the sequence of one-character strings whose concatenation is $x$.
\end{definition}

\begin{definition}[BPE Merge System]
    A BPE merge system of depth $N$ consists of vocabularies
    \[
    \boldsymbol{\Lambda}^{(0)} \subseteq \boldsymbol{\Lambda}^{(1)} \subseteq \cdots \subseteq \boldsymbol{\Lambda}^{(N)}
    \]
    and tokens $\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}, \boldsymbol{\gamma_k}$ for each
    $1 \leq k \leq N$ satisfying:
    \begin{enumerate}
        \item $\boldsymbol{\Lambda}^{(0)} = \Lambda$, where each character is regarded as a one-character token.
        \item $\boldsymbol{\alpha_k}, \boldsymbol{\beta_k} \in \boldsymbol{\Lambda}^{(k-1)}$.
        \item $\boldsymbol{\gamma_k} = \boldsymbol{\alpha_k} + \boldsymbol{\beta_k}$ as strings.
        \item $\boldsymbol{\gamma_k} \notin \boldsymbol{\Lambda}^{(k-1)}$.
        \item $\boldsymbol{\Lambda}^{(k)} = \boldsymbol{\Lambda}^{(k-1)} \cup \{\boldsymbol{\gamma_k}\}$.
    \end{enumerate}
\end{definition}

\begin{definition}[Single BPE Merge Pass]
    For $1 \leq k \leq N$, the $k$th merge pass
    \[
    M_k : (\boldsymbol{\Lambda}^{(k-1)})^* \to (\boldsymbol{\Lambda}^{(k)})^*
    \]
    is defined recursively by
    \[
    M_k([]) = [],
    \]
    \[
    M_k([\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}] + \mathbf{r})
    =
    [\boldsymbol{\gamma_k}] + M_k(\mathbf{r}),
    \]
    and
    \[
    M_k([\boldsymbol{\tau}] + \mathbf{r})
    =
    [\boldsymbol{\tau}] + M_k(\mathbf{r})
    \]
    whenever either $\mathbf{r} = []$, or the first token of $\mathbf{r}$ is not $\boldsymbol{\beta_k}$,
    or $\boldsymbol{\tau} \neq \boldsymbol{\alpha_k}$.

    Thus $M_k$ performs the left-to-right maximal non-overlapping replacement of
    $[\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}]$ by $[\boldsymbol{\gamma_k}]$.
\end{definition}

\begin{definition}[Stagewise BPE Tokenizers]
    The tokenizer after $k$ merge stages is the map
    \[
    T_k : S \to (\boldsymbol{\Lambda}^{(k)})^*
    \]
    defined recursively by
    \[
    T_0(x) = \operatorname{chars}(x),
    \qquad
    T_k(x) = M_k(T_{k-1}(x)).
    \]
    The final BPE tokenizer is $T := T_N$.
\end{definition}

\begin{definition}[Stagewise Canonicality]
    A token sequence $\mathbf{a} \in (\boldsymbol{\Lambda}^{(k)})^*$ is stage-$k$ canonical if and only if
    \[
    T_k(T^{-1}(\mathbf{a})) = \mathbf{a}.
    \]
    We denote the set of stage-$k$ canonical token sequences by $\mathbf{C}^{(k)}$.
\end{definition}

\begin{proposition}[Stage-$0$ Canonicality]
    \label{prop:bpe-stage-zero-canonicality}
    A token sequence is stage-$0$ canonical if and only if each of its tokens has length $1$.
\end{proposition}
\begin{proof}
    By definition,
    \[
    T_0(T^{-1}(\mathbf{a})) = \operatorname{chars}(T^{-1}(\mathbf{a})).
    \]
    The token sequence on the right is obtained by splitting the literalization of $\mathbf{a}$
    into one-character strings.
    Therefore it is equal to $\mathbf{a}$ if and only if every token of $\mathbf{a}$ is already
    a one-character string.
\end{proof}

\begin{definition}[Single-Stage Decompression]
    For $1 \leq k \leq N$, the single-stage decompression map
    \[
    D_k : (\boldsymbol{\Lambda}^{(k)})^* \to (\boldsymbol{\Lambda}^{(k-1)})^*
    \]
    is defined recursively by
    \[
    D_k([]) = [],
    \]
    \[
    D_k([\boldsymbol{\gamma_k}] + \mathbf{r})
    =
    [\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}] + D_k(\mathbf{r}),
    \]
    and
    \[
    D_k([\boldsymbol{\tau}] + \mathbf{r})
    =
    [\boldsymbol{\tau}] + D_k(\mathbf{r})
    \qquad
    \text{for } \boldsymbol{\tau} \neq \boldsymbol{\gamma_k}.
    \]
\end{definition}

\begin{definition}[Stage-$k$ Reduced Sequence]
    For $1 \leq k \leq N$, we say that a token sequence $\mathbf{a}$ is stage-$k$ reduced if and only if
    it contains no adjacent occurrence of the pair $[\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}]$.
    Equivalently,
    \[
    \operatorname{red}_k(\mathbf{a})
    \iff
    \not\exists i < |\mathbf{a}|-1,\;
    \mathbf{a}[i] = \boldsymbol{\alpha_k}
    \land
    \mathbf{a}[i+1] = \boldsymbol{\beta_k}.
    \]
\end{definition}

\begin{lemma}[Single-stage decompression preserves literalization]
    \label{lemma:bpe-decompression-preserves-literalization}
    For every $\mathbf{a} \in (\boldsymbol{\Lambda}^{(k)})^*$,
    \[
    T^{-1}(D_k(\mathbf{a})) = T^{-1}(\mathbf{a}).
    \]
\end{lemma}
\begin{proof}
    We argue by induction on $|\mathbf{a}|$.

    If $\mathbf{a} = []$, the claim is immediate.
    Otherwise write $\mathbf{a} = [\boldsymbol{\tau}] + \mathbf{r}$.

    If $\boldsymbol{\tau} = \boldsymbol{\gamma_k}$, then
    \[
    D_k(\mathbf{a}) = [\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}] + D_k(\mathbf{r}),
    \]
    so
    \begin{align*}
    T^{-1}(D_k(\mathbf{a}))
    &=
    \boldsymbol{\alpha_k} + \boldsymbol{\beta_k} + T^{-1}(D_k(\mathbf{r})) \\
    &=
    \boldsymbol{\gamma_k} + T^{-1}(\mathbf{r}) \\
    &=
    T^{-1}(\mathbf{a}),
    \end{align*}
    using the defining relation $\boldsymbol{\gamma_k} = \boldsymbol{\alpha_k}+\boldsymbol{\beta_k}$
    and the inductive hypothesis.

    If $\boldsymbol{\tau} \neq \boldsymbol{\gamma_k}$, then
    \[
    D_k(\mathbf{a}) = [\boldsymbol{\tau}] + D_k(\mathbf{r}),
    \]
    and therefore
    \[
    T^{-1}(D_k(\mathbf{a}))
    =
    \boldsymbol{\tau} + T^{-1}(D_k(\mathbf{r}))
    =
    \boldsymbol{\tau} + T^{-1}(\mathbf{r})
    =
    T^{-1}(\mathbf{a}),
    \]
    again by the inductive hypothesis.
\end{proof}

\begin{lemma}[Single-stage decompression respects concatenation]
    \label{lemma:bpe-decompression-append}
    For all token sequences $\mathbf{a}$ and $\mathbf{b}$,
    \[
    D_k(\mathbf{a}+\mathbf{b}) = D_k(\mathbf{a}) + D_k(\mathbf{b}).
    \]
\end{lemma}
\begin{proof}
    We argue by induction on $|\mathbf{a}|$.

    If $\mathbf{a} = []$, the claim is immediate.
    Otherwise write $\mathbf{a} = [\boldsymbol{\tau}] + \mathbf{r}$ and split on whether
    $\boldsymbol{\tau} = \boldsymbol{\gamma_k}$.
    In each case the recursive definition of $D_k$ reduces the claim to the inductive hypothesis.
\end{proof}

\begin{lemma}[Decompression inverts a merge pass]
    \label{lemma:bpe-decompression-left-inverse}
    For every $\mathbf{a} \in (\boldsymbol{\Lambda}^{(k-1)})^*$,
    \[
    D_k(M_k(\mathbf{a})) = \mathbf{a}.
    \]
\end{lemma}
\begin{proof}
    We argue by induction on $|\mathbf{a}|$.

    If $\mathbf{a} = []$, the claim is immediate.
    Otherwise write $\mathbf{a} = [\boldsymbol{\tau}] + \mathbf{r}$.

    If $\boldsymbol{\tau} = \boldsymbol{\alpha_k}$ and $\mathbf{r} = [\boldsymbol{\beta_k}] + \mathbf{r}'$,
    then
    \[
    M_k(\mathbf{a}) = [\boldsymbol{\gamma_k}] + M_k(\mathbf{r}'),
    \]
    so
    \[
    D_k(M_k(\mathbf{a}))
    =
    [\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}] + D_k(M_k(\mathbf{r}'))
    =
    [\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}] + \mathbf{r}'
    =
    \mathbf{a},
    \]
    by the inductive hypothesis.

    Otherwise,
    \[
    M_k(\mathbf{a}) = [\boldsymbol{\tau}] + M_k(\mathbf{r}),
    \]
    and since $\boldsymbol{\tau} \neq \boldsymbol{\gamma_k}$,
    \[
    D_k(M_k(\mathbf{a}))
    =
    [\boldsymbol{\tau}] + D_k(M_k(\mathbf{r}))
    =
    [\boldsymbol{\tau}] + \mathbf{r}
    =
    \mathbf{a},
    \]
    again by the inductive hypothesis.
\end{proof}

\begin{lemma}[Merge pass yields a reduced sequence]
    \label{lemma:bpe-merge-produces-reduced}
    For every $\mathbf{a} \in (\boldsymbol{\Lambda}^{(k-1)})^*$,
    \[
    \operatorname{red}_k(M_k(\mathbf{a})).
    \]
\end{lemma}
\begin{proof}
    We argue by induction on $|\mathbf{a}|$.

    If $\mathbf{a} = []$, the claim is immediate.
    Otherwise write $\mathbf{a} = [\boldsymbol{\tau}] + \mathbf{r}$.

    If $\boldsymbol{\tau} = \boldsymbol{\alpha_k}$ and $\mathbf{r} = [\boldsymbol{\beta_k}] + \mathbf{r}'$,
    then
    \[
    M_k(\mathbf{a}) = [\boldsymbol{\gamma_k}] + M_k(\mathbf{r}').
    \]
    By the inductive hypothesis, the suffix $M_k(\mathbf{r}')$ is stage-$k$ reduced.
    Since the first token is $\boldsymbol{\gamma_k}$ rather than $\boldsymbol{\alpha_k}$,
    the whole sequence is stage-$k$ reduced.

    Otherwise,
    \[
    M_k(\mathbf{a}) = [\boldsymbol{\tau}] + M_k(\mathbf{r}).
    \]
    By the inductive hypothesis, the suffix $M_k(\mathbf{r})$ is stage-$k$ reduced.
    It remains only to rule out an adjacent occurrence of
    $[\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}]$ starting at the first token.

    If $\boldsymbol{\tau} \neq \boldsymbol{\alpha_k}$, this is immediate.
    If $\boldsymbol{\tau} = \boldsymbol{\alpha_k}$, then by hypothesis the first token of $\mathbf{r}$
    is either absent or different from $\boldsymbol{\beta_k}$.
    Hence the first token of $M_k(\mathbf{r})$ is also either absent or different from $\boldsymbol{\beta_k}$.
    Therefore no adjacent occurrence of $[\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}]$
    starts at the first token.
\end{proof}

\begin{lemma}[Reduced sequences are reconstructed by decompression]
    \label{lemma:bpe-reduced-reconstruction}
    If $\operatorname{red}_k(\mathbf{a})$, then
    \[
    M_k(D_k(\mathbf{a})) = \mathbf{a}.
    \]
\end{lemma}
\begin{proof}
    We argue by induction on $|\mathbf{a}|$.

    If $\mathbf{a} = []$, the claim is immediate.
    Otherwise write $\mathbf{a} = [\boldsymbol{\tau}] + \mathbf{r}$.

    If $\boldsymbol{\tau} = \boldsymbol{\gamma_k}$, then
    \[
    D_k(\mathbf{a}) = [\boldsymbol{\alpha_k}, \boldsymbol{\beta_k}] + D_k(\mathbf{r}),
    \]
    and hence
    \[
    M_k(D_k(\mathbf{a}))
    =
    [\boldsymbol{\gamma_k}] + M_k(D_k(\mathbf{r}))
    =
    [\boldsymbol{\gamma_k}] + \mathbf{r}
    =
    \mathbf{a},
    \]
    by the inductive hypothesis.

    If $\boldsymbol{\tau} \neq \boldsymbol{\gamma_k}$, then
    \[
    D_k(\mathbf{a}) = [\boldsymbol{\tau}] + D_k(\mathbf{r}).
    \]
    Because $\operatorname{red}_k(\mathbf{a})$, either $\boldsymbol{\tau} \neq \boldsymbol{\alpha_k}$,
    or $\mathbf{r} = []$, or the first token of $\mathbf{r}$ is not $\boldsymbol{\beta_k}$.
    In all cases the first clause in the definition of $M_k$ does not apply to
    $[\boldsymbol{\tau}] + D_k(\mathbf{r})$, so
    \[
    M_k(D_k(\mathbf{a}))
    =
    [\boldsymbol{\tau}] + M_k(D_k(\mathbf{r}))
    =
    [\boldsymbol{\tau}] + \mathbf{r}
    =
    \mathbf{a},
    \]
    again by the inductive hypothesis.
\end{proof}

\begin{theorem}[Stagewise canonicality characterization]
    \label{thm:bpe-canonical-characterization}
    Let $1 \leq k \leq N$.
    Then for every token sequence $\mathbf{a} \in (\boldsymbol{\Lambda}^{(k)})^*$,
    \[
    \mathbf{a} \in \mathbf{C}^{(k)}
    \iff
    \operatorname{red}_k(\mathbf{a})
    \land
    D_k(\mathbf{a}) \in \mathbf{C}^{(k-1)}.
    \]
\end{theorem}
\begin{proof}
    We prove both implications.

    First suppose $\mathbf{a} \in \mathbf{C}^{(k)}$.
    Then
    \[
    \mathbf{a}
    =
    T_k(T^{-1}(\mathbf{a}))
    =
    M_k(T_{k-1}(T^{-1}(\mathbf{a}))).
    \]
    Therefore $\operatorname{red}_k(\mathbf{a})$ by lemma~\ref{lemma:bpe-merge-produces-reduced}.

    Also,
    \[
    D_k(\mathbf{a})
    =
    D_k(M_k(T_{k-1}(T^{-1}(\mathbf{a}))))
    =
    T_{k-1}(T^{-1}(\mathbf{a}))
    \]
    by lemma~\ref{lemma:bpe-decompression-left-inverse}. By
    lemma~\ref{lemma:bpe-decompression-preserves-literalization},
    \[
    T^{-1}(D_k(\mathbf{a})) = T^{-1}(\mathbf{a}),
    \]
    so
    \[
    T_{k-1}(T^{-1}(D_k(\mathbf{a}))) = D_k(\mathbf{a}).
    \]
    Hence $D_k(\mathbf{a}) \in \mathbf{C}^{(k-1)}$.

    Conversely, suppose
    \[
    \operatorname{red}_k(\mathbf{a})
    \qquad\text{and}\qquad
    D_k(\mathbf{a}) \in \mathbf{C}^{(k-1)}.
    \]
    Then
    \[
    T_{k-1}(T^{-1}(D_k(\mathbf{a}))) = D_k(\mathbf{a}).
    \]
    By lemma~\ref{lemma:bpe-decompression-preserves-literalization},
    \[
    T^{-1}(D_k(\mathbf{a})) = T^{-1}(\mathbf{a}),
    \]
    so
    \[
    T_k(T^{-1}(\mathbf{a}))
    =
    M_k(T_{k-1}(T^{-1}(\mathbf{a})))
    =
    M_k(D_k(\mathbf{a})).
    \]
    Since $\operatorname{red}_k(\mathbf{a})$, lemma~\ref{lemma:bpe-reduced-reconstruction} gives
    \[
    M_k(D_k(\mathbf{a})) = \mathbf{a}.
    \]
    Therefore
    \[
    T_k(T^{-1}(\mathbf{a})) = \mathbf{a},
    \]
    i.e. $\mathbf{a} \in \mathbf{C}^{(k)}$.
\end{proof}

\begin{theorem}[BPE overlap concatenation theorem]
    \label{thm:bpe-overlap-concatenation}
    For every $k \in \{0,\ldots,N\}$, if
    \[
    \mathbf{b} \neq \boldsymbol{\epsilon},
    \qquad
    \mathbf{a}+\mathbf{b} \in \mathbf{C}^{(k)}
    \qquad\text{and}\qquad
    \mathbf{b}+\mathbf{c} \in \mathbf{C}^{(k)},
    \]
    then
    \[
    \mathbf{a}+\mathbf{b}+\mathbf{c} \in \mathbf{C}^{(k)}.
    \]
\end{theorem}
\begin{proof}
    We argue by induction on $k$.

    For $k=0$, proposition~\ref{prop:bpe-stage-zero-canonicality} implies that every token
    occurring in $\mathbf{a}+\mathbf{b}$ and every token occurring in $\mathbf{b}+\mathbf{c}$
    has length $1$. Hence every token in $\mathbf{a}+\mathbf{b}+\mathbf{c}$ has length $1$,
    so $\mathbf{a}+\mathbf{b}+\mathbf{c} \in \mathbf{C}^{(0)}$ by the same proposition.

    Now let $1 \leq k \leq N$, and suppose the theorem has been proved for $k-1$.
    Assume
    \[
    \mathbf{b} \neq \boldsymbol{\epsilon},
    \qquad
    \mathbf{a}+\mathbf{b} \in \mathbf{C}^{(k)}
    \qquad\text{and}\qquad
    \mathbf{b}+\mathbf{c} \in \mathbf{C}^{(k)}.
    \]
    By theorem~\ref{thm:bpe-canonical-characterization},
    \[
    \operatorname{red}_k(\mathbf{a}+\mathbf{b}),
    \quad
    D_k(\mathbf{a}+\mathbf{b}) \in \mathbf{C}^{(k-1)},
    \quad
    \operatorname{red}_k(\mathbf{b}+\mathbf{c}),
    \quad
    D_k(\mathbf{b}+\mathbf{c}) \in \mathbf{C}^{(k-1)}.
    \]
    By lemma~\ref{lemma:bpe-decompression-append},
    \[
    D_k(\mathbf{a}+\mathbf{b}) = D_k(\mathbf{a}) + D_k(\mathbf{b}),
    \qquad
    D_k(\mathbf{b}+\mathbf{c}) = D_k(\mathbf{b}) + D_k(\mathbf{c}).
    \]
    Applying the inductive hypothesis at stage $k-1$ yields
    \[
    D_k(\mathbf{a}) + D_k(\mathbf{b}) + D_k(\mathbf{c}) \in \mathbf{C}^{(k-1)}.
    \]
    Using lemma~\ref{lemma:bpe-decompression-append} once more,
    \[
    D_k(\mathbf{a}+\mathbf{b}+\mathbf{c}) \in \mathbf{C}^{(k-1)}.
    \]

    It remains to prove that $\mathbf{a}+\mathbf{b}+\mathbf{c}$ is stage-$k$ reduced.
    Because $\mathbf{b} \neq \boldsymbol{\epsilon}$, the boundary between $\mathbf{a}$ and $\mathbf{c}$
    does not create an adjacent pair in $\mathbf{a}+\mathbf{b}+\mathbf{c}$.
    Every adjacent pair of tokens in $\mathbf{a}+\mathbf{b}+\mathbf{c}$ lies either in the prefix
    $\mathbf{a}+\mathbf{b}$ or in the suffix $\mathbf{b}+\mathbf{c}$.
    Since both of those sequences are stage-$k$ reduced, so is $\mathbf{a}+\mathbf{b}+\mathbf{c}$.

    A final application of theorem~\ref{thm:bpe-canonical-characterization} gives
    \[
    \mathbf{a}+\mathbf{b}+\mathbf{c} \in \mathbf{C}^{(k)},
    \]
    as required.
\end{proof}

\begin{corollary}[BPE last-pair extension]
    \label{cor:bpe-last-pair-extension}
    Assume the tokenization function of this chapter is induced by a BPE merge system, so that
    $\mathbf{C} = \mathbf{C}^{(N)}$.
    Let $\mathbf{a} \in \mathbf{C}$ be nonempty and let $\boldsymbol{\tau}$ be a token.
    If
    \[
    \psi(\mathbf{a}[-1], \boldsymbol{\tau}),
    \]
    then
    \[
    \mathbf{a}+\boldsymbol{\tau} \in \mathbf{C}.
    \]
\end{corollary}
\begin{proof}
    Let
    \[
    \mathbf{a}' := \mathbf{a}[:-1],
    \qquad
    \mathbf{b} := [\mathbf{a}[-1]],
    \qquad
    \mathbf{c} := [\boldsymbol{\tau}].
    \]
    Then
    \[
    \mathbf{a}'+\mathbf{b} = \mathbf{a} \in \mathbf{C}.
    \]
    Also, in the BPE specialization, the condition
    \[
    \psi(\mathbf{a}[-1], \boldsymbol{\tau})
    \]
    is exactly the statement that
    \[
    \mathbf{b}+\mathbf{c} \in \mathbf{C}.
    \]
    Applying theorem~\ref{thm:bpe-overlap-concatenation} with $k=N$ gives
    \[
    \mathbf{a}'+\mathbf{b}+\mathbf{c} \in \mathbf{C},
    \]
    i.e.
    \[
    \mathbf{a}+\boldsymbol{\tau} \in \mathbf{C}.
    \]
\end{proof}

Prior update:
\label{sec:prior-update}

After receiving an ``LLM Result'' we must update the trie to reflect this refinement of
the language model.

\textbf{Step 1: Select initial frontier:}
The ``LLM Result'' corresponds to a token sequence, $\mathbf{A}$.
We choose the corresponding character sequence, $S$, in the bayesian trie as our initial frontier.

\textbf{Step 2: Down Propagation:}
We descend from the initial frontier via valid descent until we reach a valid update leafset.
A node is known to belong to the valid update leafset, and no further descent from that
node is necessary, if and only if the node satisfies one of the following two cases:
\begin{itemize}
    \item \textbf{Valid Likelihood}: The node has never been a parent to a visible node, i.e., it has a valid likelihood.
    \item \textbf{Space Character}: The node is a space character. Formally, the condition is that there exists
    some token following upon $\mathbf{A}$ which every possible suffix of our node $S$, must contain, i.e.,
    we require that $S$ satisfy,
    $$
    \exists \mathbf{B}, \mathbf{B}>\mathbf{A}, |\mathbf{B}|=|\mathbf{A}|+1, \forall Y \geq S, \mathbf{B} < Tokenize(Y)
    $$
    but in practice we implement this by recognizing that this condition is always true of the space
    character and rarely true otherwise.
\end{itemize}

\textbf{Note Bene:} Why is descending to the space character necessary? After all,
if we know exactly how a node's prior has changed, and we know that its likelihood has not changed,
then we should be able to correctly recalculate the unnormalized posterior, just as how 
in the likelihood update we could recalculate the unnormalized posterior of a node
if we knew how its likelihood had changed and that its prior had remained constant.
The subtle fallacy in this thinking is that the \textit{likelihood of the node has changed}.
Although we often think of the likelihood as being independent of the prior,
this is only true for pure hypotheses. For a composite hypothesis, like this node we have,
$$
P(D | S) = \sum_i P(D | S_i) P(S_i | S)
$$
where $S_i$ are the children of $S$.
Since the weighting, i.e., the prior, has changed, so has the \textit{likelihood}
of this node.
Thus we do not satisfy case 4 above, because the likelihood has changed.
